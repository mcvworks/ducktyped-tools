Dev Tools

Last updated: March 8, 2026

Utilities for software developers and web engineers. Decode JWTs, test regular expressions, trace redirects, scan for broken links, inspect robots.txt rules, detect technology stacks, and audit HTTP security headers — all without leaving the browser.

Tools

Dev

JWT Decoder

Decode and inspect JSON Web Token header, payload, and signature. Verify claims, expiry, and structure without a secret key.

 Dev

JSON Formatter

Format, pretty-print, and validate JSON data with syntax highlighting. Minify or expand JSON for debugging and readability.

 Dev

Regex Tester

Test and debug regular expressions against sample text with match highlighting, capture groups, and flag support.

 Dev

Redirect Checker

Trace the full redirect chain for any URL, showing each hop with status codes, response headers, and final destination.

 Dev

Broken Link Checker

Check a webpage for broken links, dead URLs, and HTTP error responses to keep your site healthy.

 Dev

Robots.txt Analyzer

Fetch and analyze a site's robots.txt file to understand crawl directives, disallow rules, and sitemap declarations.

 Dev

Tech Stack Detector

Detect the technologies, frameworks, CMS, CDN, and server software used by any website from response headers and HTML.

 Dev

Security Headers Checker

Inspect HTTP security headers for any URL — CSP, HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy, and more.

 Dev

Plain Notes

A fast, browser-based notepad with auto-save using localStorage. No account required — your notes stay on your device.
