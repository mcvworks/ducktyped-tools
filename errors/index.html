Popular Errors
Browser Errors
Browser
DNS_PROBE_FINISHED_NXDOMAIN
Domain could not be resolved. The DNS lookup returned no results for this address.
 Browser
ERR_CONNECTION_RESET
The connection was reset while loading the page. Often a network or firewall issue.
 Browser
ERR_CONNECTION_REFUSED
The server actively refused the connection. The port may be closed or the service down.
 Browser
ERR_TOO_MANY_REDIRECTS
The page entered an infinite redirect loop and could not load.
 Browser
ERR_NAME_NOT_RESOLVED
The browser could not resolve the domain name. DNS lookup returned no usable result.
 Browser
ERR_INTERNET_DISCONNECTED
Your device has no internet connection. Check your network adapter and router.
 Browser
ERR_TIMED_OUT
The browser waited too long for the server to respond and gave up.
 Browser
ERR_NETWORK_CHANGED
The network configuration changed while a page was loading, interrupting the connection.
 Browser
ERR_CACHE_MISS
The page requires form data to be resubmitted but the browser cache is missing it.
 Browser
ERR_BLOCKED_BY_CLIENT
A browser extension blocked the request before it reached the server.
HTTP Errors
HTTP
404 Not Found
The requested page or resource does not exist on the server.
 HTTP
502 Bad Gateway
A proxy or gateway received an invalid response from the upstream server.
 HTTP
503 Service Unavailable
The server is temporarily unable to handle requests — usually maintenance or overload.
 HTTP
400 Bad Request
The server could not process the request due to malformed syntax or invalid parameters.
 HTTP
401 Unauthorized
Authentication is required and the request did not provide valid credentials.
 HTTP
403 Forbidden
The server refuses to authorize access to the requested resource.
 HTTP
405 Method Not Allowed
The HTTP method used is not allowed for the requested resource.
 HTTP
408 Request Timeout
The server closed the connection because the client took too long to send the request.
 HTTP
409 Conflict
The request conflicts with the current state of the resource on the server.
 HTTP
410 Gone
The requested resource has been permanently removed from the server.
 HTTP
415 Unsupported Media Type
The server refuses to accept the request because the Content-Type is not supported.
 HTTP
422 Unprocessable Entity
The request syntax is valid but the content fails semantic validation.
 HTTP
429 Too Many Requests
The client has sent too many requests in a short period and hit the server's rate limit.
 HTTP
500 Internal Server Error
The server encountered an unexpected error while processing the request.
 HTTP
501 Not Implemented
The server does not support the HTTP method used in the request.
 HTTP
504 Gateway Timeout
The gateway timed out waiting for an upstream server to respond.
 HTTP
507 Insufficient Storage
The server cannot store the data needed to complete the request.
DNS Errors
DNS
DNS Server Not Responding
The configured DNS server is offline or not responding to queries.
 DNS
DNS Lookup Failed
The DNS query returned no usable result for the domain you requested.
 DNS
DNS_PROBE_STARTED
Chrome is running its DNS diagnostic probe after a failed lookup attempt.
 DNS
DNS_PROBE_FINISHED_BAD_CONFIG
Chrome detected a DNS misconfiguration on your device or local network.
 DNS
DNS_PROBE_FINISHED_NO_INTERNET
Chrome's DNS probe confirmed there is no internet connection available.
 DNS
DNS SERVFAIL
The DNS server returned a server failure response code, often due to DNSSEC issues.
 DNS
NXDOMAIN
The DNS server confirmed the queried domain does not exist.
 DNS
Temporary failure in name resolution
Linux cannot resolve hostnames — resolv.conf, systemd-resolved, or WSL2 issues.
 DNS
getaddrinfo ENOTFOUND
Node.js could not resolve a hostname — typos, unset env vars, or Docker names.
 DNS
getaddrinfo EAI_AGAIN
Temporary DNS lookup failure, common inside Docker builds and CI.
 DNS
Could not resolve host
curl (exit code 6), git, and wget cannot resolve a hostname.
Email Errors
Email
SMTP 550 — Mailbox Unavailable
The recipient address was rejected. The mailbox may not exist or has been blocked.
 Email
SMTP 554 — Transaction Failed
The mail server refused the entire transaction, often due to spam filtering or policy.
 Email
SMTP 421 — Service Temporarily Unavailable
The receiving mail server closed the connection temporarily. Delivery will be retried.
 Email
SMTP 450 — Mailbox Temporarily Unavailable
The recipient mailbox is temporarily unavailable. Often caused by greylisting.
 Email
SMTP 451 — Local Processing Error
The mail server encountered a local error processing the message.
 Email
SMTP 452 — Insufficient System Storage
The receiving mail server does not have enough disk space to accept the message.
 Email
SMTP 521 — Server Does Not Accept Mail
The receiving server is configured to never accept incoming email.
 Email
SMTP 535 — Authentication Failed
SMTP authentication failed — the username or password was rejected by the mail server.
 Email
SMTP 553 — Mailbox Name Not Allowed
The email address is invalid or violates the server's naming or relay policy.
 Email
Mailbox Unavailable
The recipient's email account cannot receive messages — may be full, disabled, or non-existent.
SSL / TLS Errors
SSL
ERR_SSL_PROTOCOL_ERROR
The SSL handshake failed due to a protocol version mismatch or misconfigured certificate.
 SSL
SSL Handshake Failed
The browser and server could not complete TLS negotiation to establish a secure connection.
 SSL
SSL Certificate Expired
The site's SSL certificate has passed its validity end date and must be renewed.
 SSL
SSL Certificate Revoked
The certificate authority revoked this certificate before its expiry date.
 SSL
SSL Certificate Invalid
The SSL certificate failed browser validation for one or more reasons.
 SSL
NET::ERR_CERT_DATE_INVALID
The certificate's validity dates do not match the current date — often a clock skew issue.
 SSL
NET::ERR_CERT_AUTHORITY_INVALID
The certificate was issued by a Certificate Authority the browser does not trust.
 SSL
NET::ERR_CERT_WEAK_SIGNATURE_ALGORITHM
The certificate uses a deprecated weak signature algorithm such as SHA-1.

 DevOps

 DevOps

 DevOps

 DevOps

 DevOps

Database Errors
Database

 Database

 Database

Database connection attempt timed out. Check network and firewall settings.
 Database
Too Many Database Connections

 Database

Redis server refused the connection. Check if Redis is running.
 Database

 Database

 Database

 Database

 Database
