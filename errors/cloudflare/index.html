Cloudflare Errors

Cloudflare sits between visitors and the origin server, so its error pages describe which side broke: the 52x codes are origin-connection problems (down, timing out, TLS misconfigured), while the 1xxx codes are Cloudflare security features acting on the request. Each guide covers both perspectives — what a visitor can do, and what the site owner must fix. Generic 502/504 pages are cross-listed from the HTTP category.

Cloudflare Error 1015 — You Are Being Rate Limited
The request tripped a Rate Limiting rule configured by the site's owner — too many requests from your IP inside the rule's time window.
 Cloudflare
Cloudflare Error 1016 — Origin DNS Error
Cloudflare could not resolve the origin's address: the DNS record behind the proxy points at a hostname that does not resolve — a broken CNAME target is the classic cause.
 Cloudflare
Cloudflare Error 1020 — Access Denied
The request matched a firewall or WAF rule on the site — country, network, user-agent, path, or bot-score conditions the owner configured (or a managed rule).
 Cloudflare
Cloudflare Error 520 — Web Server Returns an Unknown Error
Cloudflare reached the origin server, but the response was empty, malformed, or cut off — something Cloudflare could not interpret as valid HTTP.
 Cloudflare
Cloudflare Error 521 — Web Server Is Down
Cloudflare tried to connect to the origin server and the connection was actively refused — nothing is accepting connections on the origin's port.
 Cloudflare
Cloudflare Error 522 — Connection Timed Out
Cloudflare's attempt to open a TCP connection to the origin produced no answer at all within the timeout — packets are being dropped, or the origin is too overloaded to accept.
 Cloudflare
Cloudflare Error 523 — Origin Is Unreachable
Cloudflare has no network route to the origin at all — typically because the DNS record points at a private, wrong, or no-longer-routed IP address.
 Cloudflare
Cloudflare Error 524 — A Timeout Occurred
Cloudflare connected to the origin and delivered the request, but the origin did not complete an HTTP response within 100 seconds — long jobs and slow queries are the usual story.
 Cloudflare
Cloudflare Error 525 — SSL Handshake Failed
Cloudflare tried to establish a TLS connection to the origin (Full or Full-strict SSL mode) and the handshake failed — usually no certificate is being served on port 443.
 Cloudflare
Cloudflare Error 526 — Invalid SSL Certificate
Under Full (strict) SSL mode, the origin presented a certificate that failed validation — expired, self-signed, untrusted, or issued for a different hostname.
 Cloudflare
Cloudflare Errors 1006, 1007, 1008 — Access Denied: IP Banned
The page 'Access denied: the owner of this website has banned your IP address' — an IP Access Rule on the site explicitly blocks your address or range.
 Cloudflare
Cloudflare Redirect Loop (ERR_TOO_MANY_REDIRECTS)
The browser reports ERR_TOO_MANY_REDIRECTS on a site behind Cloudflare — almost always Flexible SSL mode fighting an origin that redirects HTTP to HTTPS.
 Browser
ERR_TOO_MANY_REDIRECTS
The page entered a redirect loop and could not load.
