SSL Certificate Invalid

Last updated: March 8, 2026

SSL Certificate Invalid is an umbrella error for any certificate validation failure. The browser cannot verify the certificate is trustworthy — for any of several possible reasons.

You might see this error as:

  • SSL certificate invalid
  • Invalid certificate
  • Certificate verification failed
  • ERR_CERT_INVALID

What Does This Error Mean?

When a browser connects to an HTTPS site, it validates the server's SSL certificate through a chain of checks. If any check fails, the browser shows some form of "certificate invalid" warning and blocks the connection.

The specific reason for the failure is usually shown in the detailed error message. Use the SSL Checker to inspect the full certificate chain and identify the exact problem.

Types of Certificate Invalidity

Expired Certificate

The certificate's Not After date has passed. Chrome shows NET::ERR_CERT_DATE_INVALID. Fix: renew the certificate.

Hostname Mismatch

The certificate does not cover the domain you are visiting. Chrome shows ERR_CERT_COMMON_NAME_INVALID. Fix: reissue with the correct hostname(s) in the SANs.

Untrusted Certificate Authority

The certificate was signed by a CA not in the browser's trusted root store (e.g., a self-signed cert, an internal CA, or an expired root CA). Chrome shows NET::ERR_CERT_AUTHORITY_INVALID. Fix: use a publicly trusted CA like Let's Encrypt.

Revoked Certificate

The CA has revoked the certificate. Chrome shows NET::ERR_CERT_REVOKED. Fix: issue a new certificate immediately.

Incomplete Certificate Chain

The server is not sending intermediate CA certificates, so browsers cannot build the trust chain from the leaf certificate to a trusted root. Fix: configure your web server to include the full chain file.

Weak Signature Algorithm

The certificate uses a deprecated algorithm like SHA-1. Chrome shows NET::ERR_CERT_WEAK_SIGNATURE_ALGORITHM. Fix: reissue with SHA-256.

How to Diagnose the Specific Issue

  1. Use the SSL Checker to inspect the full certificate and chain.
  2. Click "Advanced" in Chrome's error page — it shows the specific NET:: error code.
  3. Check Firefox's detailed security error page for the exact SEC_ERROR code.

Frequently Asked Questions

Can a valid certificate show as invalid due to client issues?

Yes. An incorrect system clock makes valid certificates appear expired. Missing root CA updates on older operating systems can make newer CAs appear untrusted. On very old Android devices, Let's Encrypt's root may not be trusted.

Related Errors

  • SSL Certificate Revoked — certificate invalidated by CA.
  • NET::ERR_CERT_AUTHORITY_INVALID — untrusted CA.
  • ERR_CERT_COMMON_NAME_INVALID — hostname mismatch.
