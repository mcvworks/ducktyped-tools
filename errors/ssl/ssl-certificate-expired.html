SSL Certificate Expired

Last updated: March 8, 2026

This error means the site's SSL certificate is past its validity end date. Browsers block these sites to protect users from outdated security configurations.

You might see this error as:

  • SSL certificate expired
  • Certificate has expired
  • SEC_ERROR_EXPIRED_CERTIFICATE
  • Your connection is not private
  • NET::ERR_CERT_DATE_INVALID

What Does This Error Mean?

SSL/TLS certificates have a validity period — a start date and an end date (typically shown as "Not Before" and "Not After" in the certificate). Browsers check these dates on every connection. If the current date is past the certificate's end date, the browser shows an expiry warning and blocks the connection by default.

Browser messages for this include NET::ERR_CERT_DATE_INVALID in Chrome, SEC_ERROR_EXPIRED_CERTIFICATE in Firefox, and "Your connection isn't private" with an expired certificate warning.

How Long Are SSL Certificates Valid?

As of 2020, the maximum validity for publicly trusted SSL certificates is 398 days (~13 months). Let's Encrypt certificates are valid for 90 days and designed to be renewed every 60 days. Older certificates from before 2020 may have had longer lifetimes.

How to Fix an Expired Certificate

For Site Owners

1. Renew Let's Encrypt Certificates

If using certbot:

sudo certbot renew
sudo systemctl reload nginx   # or apache2

If the certificate expired because auto-renewal failed, check the certbot timer:

systemctl status certbot.timer

2. Renew Paid Certificates

Purchase a new certificate from your CA and install it. Download the new certificate and chain files, update your web server configuration, and reload the server.

3. Set Up Auto-Renewal

Configure certbot's systemd timer or cron job to run certbot renew twice daily. Most hosting panels (cPanel, Plesk) have built-in auto-renewal. Cloudflare's managed certificates renew automatically.

4. Set Up Expiry Monitoring

Use the SSL Checker to check your current certificate's expiry date. Set calendar reminders or use a monitoring service to alert you 30 days before expiry.

For Visitors

If you trust the site (e.g., it is your own or an internal tool), you can click "Advanced" → "Proceed" to bypass the warning. Never do this on public sites where you enter login credentials or payment information.

Frequently Asked Questions

Why did my Let's Encrypt certificate expire if auto-renewal is set up?

Common reasons: the certbot renewal process failed silently (check /var/log/letsencrypt/letsencrypt.log), the server's port 80 or 443 was blocked during renewal, the domain's DNS was pointing elsewhere during the HTTP challenge, or the certbot cron job was disabled.

Can I check certificate expiry without a tool?

Click the padlock in your browser → Connection is secure → Certificate is valid → view the "Expires" date. Or use OpenSSL: echo | openssl s_client -connect domain.com:443 2>/dev/null | openssl x509 -noout -dates

Related Errors

  • NET::ERR_CERT_DATE_INVALID — certificate date validation failure.
  • SSL Certificate Revoked — certificate revoked by the CA.
  • SSL Certificate Invalid — generic certificate validation failure.
  • ERR_CERT_COMMON_NAME_INVALID — certificate hostname mismatch.
