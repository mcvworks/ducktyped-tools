SMTP 521 — Server Does Not Accept Mail

Last updated: March 8, 2026

SMTP 521 means the receiving server is explicitly configured not to accept any incoming mail. This is a permanent 5xx rejection — the message will not be delivered.

You might see this error as:

  • SMTP 521
  • 521 Does not accept mail
  • 521 Server does not accept mail

What Does This Error Mean?

The standard 521 response is: "521 <domain> does not accept mail (see RFC 7504)." RFC 7504 defines this code for systems that are intentionally configured to never accept inbound SMTP. Unlike spam rejections or authentication failures, 521 is a deliberate policy — the server is not set up to receive mail at all.

Common Causes

  • Outbound-only mail server — a server configured only to send mail, not receive it (e.g., a transactional email relay).
  • Null MX record (RFC 7505) — the domain has published a null MX record (0 .) to explicitly declare it does not accept email.
  • Web/application server handling port 25 — a non-mail server responding on SMTP port with a rejection.
  • Anti-spam gateway misconfiguration — a gateway returning 521 instead of forwarding to the correct mail server.
  • Incorrect MX record — the domain's MX record points to a server not configured to receive mail.

How to Fix It

For Senders

1. Verify the Recipient's Email Address

The email address may be for a domain that does not accept email. Confirm the address is correct with the recipient via another channel.

2. Check MX Records

Use the DNS Lookup tool to look up the MX records for the recipient's domain. If no MX records exist, or if a null MX (0 .) is configured, the domain is intentionally configured to not accept email.

For Domain Owners Receiving This Error

3. Configure MX Records Correctly

If your domain is intended to receive email, ensure your MX records point to a properly configured mail server that accepts inbound SMTP on port 25.

4. Remove Null MX If Unintentional

If you have a null MX record (0 .) but want to receive email, remove it and add a proper MX record pointing to your mail server.

Frequently Asked Questions

What is a null MX record?

A null MX record is a DNS MX record with a priority of 0 and a target of . (the root domain). Defined in RFC 7505, it explicitly signals that the domain does not accept email, preventing mail servers from attempting delivery.

Can 521 ever be resolved by retrying?

No. Since 521 starts with 5, it is a permanent failure code. The sending MTA will not retry — it will immediately bounce the message back to the sender with a non-delivery report.
