SMTP 421 — Service Temporarily Unavailable

Last updated: March 8, 2026

SMTP 421 means the receiving mail server is temporarily unavailable. The connection was closed, but the message is not permanently rejected — your server should retry.

You might see this error as:

  • SMTP 421
  • 421 Service not available
  • 421 Too many connections
  • 421 Try again later
  • SMTP temporary rejection

What Does This Error Mean?

SMTP response codes starting with 4xx indicate temporary failures. A 421 response specifically means the receiving mail server has closed the connection and is not accepting messages right now, but it should be available again soon. The full message often reads: "421 Service not available, closing transmission channel."

Your sending mail server will queue the message and attempt redelivery automatically. This is different from 5xx errors — a 421 is never a permanent rejection.

Common Causes

  • Receiving server overloaded — too many simultaneous inbound connections.
  • Server maintenance — the receiving mail server is being updated or restarted.
  • Connection limit reached — the server has hit its maximum concurrent connection limit.
  • Anti-spam rate limiting — the receiving server is throttling inbound connections from your IP.
  • Temporary IP block — your sending IP was temporarily flagged and is being rate-limited.
  • DNS MX record lookup failure — the sending server could not resolve the MX record on that attempt.

How to Handle It

1. Wait for Automatic Retry

If your mail server is properly configured, it will automatically retry delivery. Most MTAs retry at intervals (e.g., 5 min, 15 min, 30 min, 1 hour) for up to 4–5 days before sending a non-delivery report (NDR).

2. Check Your Mail Queue

Monitor your mail server queue to confirm the message is being retried. If messages are stuck or not retrying:

# Postfix
postqueue -p
postqueue -f    # flush queue (force retry)

3. Check Sending IP Reputation

If you frequently receive 421 errors from the same destination, your sending IP may be on a temporary block list or throttle. Use the Blacklist Checker to verify your IP's reputation.

4. Verify MX Records

Confirm the destination domain's MX records are valid and the mail servers are online using the DNS Lookup tool.

5. Review Your SMTP Connection Rate

If sending bulk email, reduce the number of simultaneous connections to the receiving server. Many providers throttle senders that open too many connections at once.

Frequently Asked Questions

How long will my mail server retry before bouncing?

Most MTAs retry for 4–5 days. Postfix defaults to maximal_queue_lifetime = 5d. After the retry period expires without successful delivery, the sender receives an NDR (bounce message).

Does a 421 mean the recipient's server is down?

Not necessarily. The server is reachable enough to send the 421 response, so it is not completely down. It may be overloaded, rate-limiting connections, or in a brief maintenance state. Most 421 errors resolve within minutes to hours.

Related Errors

  • SMTP 450 — mailbox temporarily unavailable.
  • SMTP 451 — local error in processing.
  • SMTP 550 — permanent mailbox unavailable.
  • SMTP 554 — transaction permanently failed.
