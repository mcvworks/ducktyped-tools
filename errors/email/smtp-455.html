SMTP 455 — Server Unable to Accommodate

Last updated: March 8, 2026

SMTP server temporarily unable to accommodate the request

You might see this error as:

  • SMTP 455
  • 455 Server unable to accommodate
  • 455 Temporary authentication failure

What Does This Error Mean?

SMTP 455 is a temporary failure response indicating that the mail server cannot process the request at this time but may be able to in the future. The enhanced status code 4.7.5 specifically relates to cryptographic or policy failures. This is a transient error, meaning the sending server should retry delivery after a delay. The server may be experiencing resource constraints, temporary policy restrictions, or configuration issues that prevent it from handling the current request.

Common Causes

  • Server resource exhaustion — The mail server has temporarily run out of resources such as disk space, memory, or available processing threads, and cannot accept additional messages until resources are freed.
  • TLS negotiation failure — The server requires TLS encryption for the connection but the TLS handshake failed due to certificate issues, cipher suite incompatibility, or TLS version mismatch.
  • Rate limiting applied — The sending server or IP address has exceeded the receiving server's rate limits for incoming connections or messages, triggering a temporary rejection.
  • Backend mail store unavailable — The mail server's backend storage system (such as a database or maildir filesystem) is temporarily unavailable, preventing the server from accepting new messages.

How to Fix It

1. Retry delivery later

SMTP 455 is a temporary error. Most mail servers automatically retry delivery using exponential backoff. Wait and check whether the message is delivered after the retry interval.

2. Check TLS configuration

If the error is related to TLS, verify that your sending server supports the TLS versions and cipher suites required by the receiving server.

# Test TLS connection to mail server
openssl s_client -connect mail.example.com:25 -starttls smtp

# Check supported TLS versions
openssl s_client -connect mail.example.com:25 -starttls smtp -tls1_2

3. Monitor server resources

If you manage the receiving server, check disk space, memory usage, and mail queue size. Clear the queue of stuck messages and free disk space if needed.

# Check disk space
df -h

# Check mail queue (Postfix)
postqueue -p

# Flush stuck messages
postqueue -f

Frequently Asked Questions

Will my email be delivered eventually?

In most cases, yes. The sending server will retry delivery automatically. Most mail servers retry for up to 4-5 days before giving up and returning a permanent bounce.

How is SMTP 455 different from SMTP 452?

SMTP 452 specifically indicates insufficient storage on the server. SMTP 455 is a more general 'unable to accommodate' error that can cover resource issues, policy failures, and TLS problems.

Should I contact the recipient's mail administrator?

Only if the error persists for more than a few hours. Transient errors usually resolve on their own. If delivery fails after multiple retries over 24 hours, contacting the administrator may be warranted.
