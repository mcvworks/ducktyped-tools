SMTP 452 — Insufficient System Storage

Last updated: March 8, 2026

SMTP 452 means the receiving mail server does not have enough disk space to accept the message. It is a temporary error — delivery will be retried.

You might see this error as:

  • SMTP 452
  • 452 Insufficient system storage
  • 452 Too many recipients
  • 452 Mailbox full

What Does This Error Mean?

The full response is typically: "452 Requested action not taken: insufficient system storage." The receiving server received the connection and was ready to accept the message, but hit a disk space limit before or during transfer.

This is a server-side resource problem. Since it is a 4xx code, the sending server will queue the message and retry. If disk space is freed up on the receiving server before the retry window expires, delivery succeeds.

Common Causes

  • Mail server disk full — the server's storage partition is at capacity.
  • User mailbox over quota — the recipient's individual mailbox quota is exceeded.
  • Mail spool overflow — the temporary spool directory used for incoming messages is full.
  • Too many messages in mail queue — a large backlog has consumed the available space.
  • Log files consuming disk — mail server logs have grown too large.
  • Large attachment rejected — some servers return 452 when a message is too large, though 552 or 550 is more common for this.

How to Fix It

For Receiving Server Administrators

1. Free Up Disk Space

df -h                   # check disk usage
du -sh /var/mail/*      # check mailbox sizes
du -sh /var/log/mail*   # check log sizes

Delete or archive old mail logs. Clear any stuck or expired messages from the mail queue.

2. Implement Mailbox Quotas

Set per-user mailbox quotas to prevent any single mailbox from consuming all available storage. In Postfix/Dovecot, configure quota plugin settings.

3. Add Storage or Archive

If disk space is consistently full, expand storage capacity or implement email archiving to move old messages to cheaper storage.

For Senders

4. Wait for Automatic Retry

If the receiving server's disk space issue is resolved, your queued message will be delivered automatically on the next retry cycle.

5. Contact the Recipient

If the error persists over multiple days, contact the recipient via another channel to let them know their mail server has storage issues.

Frequently Asked Questions

Is 452 the same as a full inbox?

Related but different. A full individual mailbox usually produces SMTP 450 or SMTP 550 (depending on whether it is temporary or permanent). SMTP 452 refers specifically to a system-level storage problem — the entire server's disk is full, not just one user's quota.

Related Errors

  • SMTP 421 — server temporarily unavailable.
  • SMTP 450 — mailbox temporarily unavailable.
  • SMTP 451 — local processing error.
  • Mailbox Unavailable — mailbox cannot receive messages.
