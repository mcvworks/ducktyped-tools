Mailbox Unavailable

Last updated: March 8, 2026

Mailbox Unavailable means the recipient's email account cannot receive messages right now — either temporarily or permanently. The SMTP response code tells you which.

You might see this error as:

  • Mailbox unavailable
  • 550 Mailbox unavailable
  • User unknown
  • No such user
  • Recipient rejected

What Does This Error Mean?

The phrase "mailbox unavailable" appears in several SMTP error responses. The exact meaning depends on the response code:

  • 4xx (temporary) — the mailbox exists but cannot receive messages right now. Delivery will be retried. Examples: 450, 451.
  • 5xx (permanent) — the mailbox cannot receive messages and the error is not expected to resolve. The message bounces immediately. Examples: 550, 551, 552.

Temporary Mailbox Unavailability (4xx)

Causes

  • Mailbox is locked by an active session
  • Mailbox is temporarily over quota
  • Mail server is under maintenance
  • Greylisting (first-time sender temporarily deferred)
  • Server rate-limiting inbound connections

Resolution

Wait for the sending server's automatic retry. Most 4xx errors resolve within hours. If the problem persists over multiple days, contact the recipient.

Permanent Mailbox Unavailability (5xx)

Causes

  • Mailbox does not exist (address was never created or has been deleted)
  • Account has been suspended or deactivated
  • Recipient's domain has no mail server
  • Mailbox permanently over quota (some servers return permanent failure)
  • Sender blocked by the recipient

Resolution

A 5xx bounce means the message will not be delivered. Contact the recipient through another channel to get a valid email address.

How to Diagnose Mailbox Unavailability

1. Read the Bounce Message

Non-delivery reports (NDRs) include the full SMTP response code and often a human-readable explanation. The code indicates whether it is temporary (4xx) or permanent (5xx).

2. Check MX Records

Verify the domain has active MX records using the DNS Lookup tool. Missing MX records mean no mail server is configured for the domain.

3. Test SMTP Connectivity

Use the SMTP Checker to test whether the destination mail server is online and accepting connections.

Frequently Asked Questions

Can an email address be valid but the mailbox still unavailable?

Yes. An email address can be syntactically valid and have valid MX records, but the account may have been deleted, suspended, or have the mailbox consistently full. Validity checking can only tell you so much — actual delivery attempts reveal the true status.

How do I remove bounced addresses from my mailing list?

For permanent (5xx) bounces, remove the address immediately. For temporary (4xx) bounces, do not remove — wait for delivery to succeed or fail after the retry period. Most email marketing platforms handle this automatically with bounce management.

Related Errors

  • SMTP 450 — mailbox temporarily unavailable.
  • SMTP 550 — mailbox permanently unavailable.
  • SMTP 452 — server storage full.
  • SMTP 554 — transaction failed.
