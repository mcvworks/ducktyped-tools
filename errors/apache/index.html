Apache Errors

Apache httpd logs its errors with AH codes (AH00558, AH01630, AH00526...) that pinpoint the failing module and condition. These guides decode the most common ones — startup failures, permission denials, .htaccess problems, proxy errors, and TLS mistakes — with the exact log lines and fixes.

Apache AH00023 — No Space Left on Device (Mutex/Semaphore)
The startup failure 'No space left on device: AH00023: Couldn't create the mpm-accept mutex' — usually exhausted semaphores, not an actually full disk.
 Apache
Apache AH00035 — Search Permissions Missing on a Component of the Path
The error-log line 'AH00035: access to / denied ... because search permissions are missing on a component of the path' — the Apache user cannot traverse a directory above the docroot.
 Apache
Apache AH00072 — make_sock: Could Not Bind to Address
The startup failure '(98)Address already in use: AH00072: make_sock: could not bind to address [::]:80' — another process holds Apache's port, or Apache is fighting itself.
 Apache
Apache AH00161 — MaxRequestWorkers Reached
The warning 'AH00161: server reached MaxRequestWorkers setting, consider raising the MaxRequestWorkers setting' — Apache is out of workers and queueing or refusing requests.
 Apache
Apache AH00526 — Syntax Error in Configuration
The configtest/startup failure 'AH00526: Syntax error on line N of file' — Apache cannot parse the configuration and refuses to start or reload until it is fixed.
 Apache
Apache AH00558 — Could Not Reliably Determine FQDN
The startup message 'AH00558: apache2: Could not reliably determine the server's fully qualified domain name' — Apache has no ServerName and is guessing.
 Apache
Apache AH00898 — Error Reading from Remote Server (mod_proxy)
The error-log line 'AH00898: Error reading from remote server' (with AH01102 'error reading status line') — Apache's reverse proxy lost the backend mid-request. Visitors see 502.
 Apache
Apache AH01071 — Got Error 'Primary Script Unknown' (PHP-FPM)
The error-log line 'AH01071: Got error \'Primary script unknown\'' — Apache proxied a request to PHP-FPM, which could not find the script. Browsers show 'File not found.'
 Apache
Apache AH01276 — Cannot Serve Directory
The error-log line 'AH01276: Cannot serve directory ...: No matching DirectoryIndex ... found, and server-generated directory index forbidden by Options directive' — visitors see 403.
 Apache
Apache AH01630 — Client Denied by Server Configuration
The error-log line 'AH01630: client denied by server configuration' — an authorization rule (usually Require directives) rejected the request. Visitors see 403 Forbidden.
 Apache
Apache AH02565 — Certificate and Private Key Do Not Match
The startup failure 'AH02565: Certificate and private key ... from ... and ... do not match' — SSLCertificateFile and SSLCertificateKeyFile are not a pair.
 Apache
Apache Invalid Command 'RewriteEngine'
The error "Invalid command 'RewriteEngine', perhaps misspelled or defined by a module not included in the server configuration" — mod_rewrite (or another module) is not enabled.
 Apache
Apache Threaded MPM vs PHP Module Conflict
The error 'Apache is running a threaded MPM, but your PHP Module is not compiled to be threadsafe. You need to recompile PHP.' — mod_php demands the prefork MPM.
