DNS_PROBE_FINISHED_BAD_CONFIG

Last updated: March 8, 2026

This error means Chrome detected a DNS misconfiguration on your device or network. The DNS server may be reachable but is returning unexpected or invalid results.

You might see this error as:

  • DNS_PROBE_FINISHED_BAD_CONFIG
  • DNS bad config
  • DNS probe finished bad config
  • DNS configuration error

What Does This Error Mean?

After a DNS lookup fails, Chrome runs a diagnostic probe. DNS_PROBE_FINISHED_BAD_CONFIG is the result when Chrome determines the problem is a configuration error — specifically, the DNS resolver is returning results that do not make sense, such as invalid IP addresses, unexpected redirects, or responses that indicate the DNS client itself is misconfigured.

This differs from NXDOMAIN (domain doesn't exist) and DNS Server Not Responding (server unreachable). BAD_CONFIG means the configuration is wrong rather than the domain or server being absent.

Common Causes

  • Incorrect DNS server IP — the configured DNS server address is wrong (e.g., a typo in the network adapter settings).
  • DNS hijacking — malware or a compromised router redirecting DNS to a different server.
  • VPN DNS misconfiguration — a VPN client that overrides DNS settings improperly.
  • Antivirus DNS filtering returning bad responses — security software intercepting DNS and returning invalid results.
  • Corrupted network adapter settings — the TCP/IP stack or DNS configuration is in an invalid state.
  • ISP DNS returning NXDOMAIN for all queries — some ISP DNS implementations return invalid responses for unresolved domains.

How to Fix It

1. Switch to a Public DNS Server

Change your DNS server to Cloudflare (1.1.1.1 / 1.0.0.1) or Google (8.8.8.8 / 8.8.4.4) in your network adapter settings.

2. Flush DNS Cache

  • Windows: ipconfig /flushdns
  • macOS: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

3. Reset TCP/IP Stack (Windows)

Open Command Prompt as administrator:

netsh int ip reset
netsh winsock reset
ipconfig /release
ipconfig /renew

Restart your computer after running these commands.

4. Check for DNS Hijacking

Open your network adapter properties and verify the DNS server IPs are what you set them to be. If they have changed without your knowledge, malware may have modified them. Run a malware scan.

5. Disable VPN or Security Software Temporarily

Test whether the error persists with VPN and antivirus DNS filtering disabled to determine if they are interfering.

Frequently Asked Questions

Can BAD_CONFIG affect all websites or just specific ones?

It typically affects all or most websites because the DNS configuration is broken at the system level. If only specific sites are affected, the issue may be ISP-level DNS filtering or domain-specific DNS problems.

Could a router firmware update cause DNS_PROBE_FINISHED_BAD_CONFIG?

Yes. A firmware update could reset or change the router's DNS forwarder configuration. After updating router firmware, verify DNS settings in the router's admin panel.

Related Errors

  • DNS Server Not Responding — DNS server offline.
  • ERR_NAME_NOT_RESOLVED — DNS resolution failed.
  • DNS_PROBE_STARTED — DNS diagnostic in progress.
