DNS FORMERR

Last updated: March 8, 2026

DNS format error in the query

You might see this error as:

  • DNS FORMERR
  • Format Error DNS
  • RCODE 1
  • DNS query format error
  • Malformed DNS query

What Does This Error Mean?

DNS FORMERR (RCODE 1) is returned by a DNS server when it receives a query that is malformed or contains formatting errors that prevent the server from parsing it. The query may have an invalid header, unsupported flags, malformed domain name labels, or include EDNS options that the server cannot process. This is relatively rare in normal browsing because DNS clients generate well-formed queries, but it can occur with specific software, EDNS0 incompatibilities, or network equipment that corrupts DNS packets.

Common Causes

  • EDNS0 incompatibility — The client sent a query with EDNS0 (Extension Mechanisms for DNS) options that the server does not understand or support. Some older DNS servers return FORMERR when they encounter OPT pseudo-records.
  • Corrupted DNS packet — A network device, firewall, or NAT gateway modified the DNS packet in transit, corrupting the binary format so that the server cannot parse the query correctly.
  • Invalid query type or class — The DNS query specifies a record type or class that the server does not recognize or considers invalid, causing it to reject the query as malformed.
  • DNS proxy or forwarder bug — A local DNS proxy, home router firmware, or DNS forwarder has a bug that generates malformed queries when forwarding requests to upstream servers.

How to Fix It

1. Bypass local DNS proxy

If your router or local DNS proxy is generating malformed queries, configure your system to use a public DNS server directly, bypassing the local proxy.

# Set DNS directly to bypass router DNS proxy
# Google DNS: 8.8.8.8, 8.8.4.4
# Cloudflare DNS: 1.1.1.1, 1.0.0.1

2. Disable EDNS0 for testing

If you suspect EDNS0 incompatibility, test with EDNS0 disabled using dig to confirm.

# Query with EDNS0 disabled
dig +noedns example.com @your-dns-server

# Compare with EDNS0 enabled (default)
dig example.com @your-dns-server

3. Update router firmware

If the FORMERR is caused by your router's DNS proxy, update the router firmware to the latest version. Router DNS implementations often have bugs that are fixed in newer firmware releases.

4. Try a different DNS server

If a specific DNS server returns FORMERR, try querying a different server. The issue may be with that server's implementation rather than your query.

Frequently Asked Questions

Is FORMERR a problem with my computer or the DNS server?

It can be either. If your DNS client software or a network device is generating malformed queries, the problem is on your side. If the server has a buggy implementation that rejects valid queries, the problem is on the server side. Testing with dig from a clean system can help isolate the cause.

Why do I get FORMERR from one DNS server but not another?

Different DNS servers have different levels of tolerance for edge cases in the DNS protocol. A server with strict parsing may return FORMERR for queries that another server handles gracefully, particularly around EDNS0 options.

Can FORMERR affect only specific domains?

FORMERR is typically about the query format rather than the domain being queried. However, if the issue is related to specific query types (such as querying for HTTPS records) that trigger EDNS0 features, it may appear to be domain-specific.
