DNS_PROBE_NETWORK_CHANGE

Last updated: March 8, 2026

DNS probe detected a network change during resolution

You might see this error as:

  • DNS_PROBE_NETWORK_CHANGE
  • DNS network change detected
  • A network change was detected

What Does This Error Mean?

DNS_PROBE_NETWORK_CHANGE occurs when Chrome detects that the underlying network configuration changed while a DNS probe was in progress. This happens when the system switches between Wi-Fi networks, toggles between Wi-Fi and cellular data, connects or disconnects from a VPN, or when DHCP renews the IP address and assigns new DNS servers. Chrome aborts the in-progress DNS probe because the network context has changed.

Common Causes

  • Wi-Fi network switch — The device automatically switched from one Wi-Fi network to another (for example, from a weak access point to a stronger one), causing the DNS resolver configuration to change mid-query.
  • VPN connection or disconnection — A VPN client connected or disconnected while the page was loading, changing the DNS server configuration and network routing in the middle of an active DNS probe.
  • DHCP lease renewal with new settings — The DHCP server renewed the network lease and assigned different DNS servers or a different IP address, invalidating the previous DNS probe context.
  • Mobile data and Wi-Fi handoff — On mobile devices or laptops with both cellular and Wi-Fi, the operating system switched between connection types while Chrome was performing DNS resolution.

How to Fix It

1. Reload the page

Once the network change completes and the new connection stabilizes, simply reload the page. Chrome will use the updated DNS configuration for the new query.

2. Stabilize your network connection

If you are in an area with competing Wi-Fi networks, manually select and lock to a specific network. Disable auto-connect for networks you do not intend to use.

3. Flush DNS after network changes

After switching networks, flush the DNS cache to clear stale records from the previous network's DNS server.

# Windows
ipconfig /flushdns

# macOS
sudo dscacheutil -flushcache

# Chrome internal cache
# Navigate to chrome://net-internals/#dns
# Click 'Clear host cache'

4. Use static DNS servers

Configure static DNS servers instead of relying on DHCP-assigned ones. This prevents DNS configuration changes during lease renewals or network switches.

Frequently Asked Questions

Why does this happen when my VPN connects?

VPN clients typically change the system DNS configuration to route DNS queries through the VPN tunnel. If Chrome is performing a DNS lookup at the exact moment the VPN modifies the DNS settings, the in-progress probe is invalidated.

Is this error harmful or does it indicate a security issue?

No, this is a benign error caused by a network configuration change. It is not a security issue. Simply reload the page once your network connection stabilizes.
