DNS_PROBE_STARTED

Last updated: March 8, 2026

DNS_PROBE_STARTED is a temporary Chrome status, not a final error. Chrome is running its DNS diagnostic after a failed lookup and will display a more specific error once the probe completes.

You might see this error as:

  • DNS_PROBE_STARTED
  • DNS probe started error
  • DNS resolution in progress

What Does This Mean?

When Chrome cannot resolve a domain name, it does not immediately show an error page. Instead, it first runs an internal DNS diagnostic probe to determine the root cause. DNS_PROBE_STARTED is the status shown during this diagnostic phase.

Within a second or two, the probe will finish and Chrome will display a more specific error:

  • DNS_PROBE_FINISHED_NXDOMAIN — domain does not exist
  • DNS_PROBE_FINISHED_BAD_CONFIG — local DNS misconfiguration
  • ERR_NAME_NOT_RESOLVED — DNS server unreachable
  • DNS_PROBE_FINISHED_NO_INTERNET — no internet connection

Why DNS_PROBE_STARTED Gets "Stuck"

In some cases, the probe itself gets stuck and DNS_PROBE_STARTED remains displayed for an extended time. This usually means:

  • DNS server is not responding at all — the probe is waiting for a timeout from an unresponsive server.
  • Network congestion — DNS queries are being delayed.
  • Chrome DNS probe loop — a bug or corrupted Chrome profile causing repeated probe cycles.
  • Firewall blocking the probe packets — diagnostic DNS queries being dropped.

How to Fix It

1. Wait and Check the Final Error

In most cases, let the probe complete. The subsequent specific error will tell you exactly what to fix.

2. Flush DNS Cache

  • Windows: ipconfig /flushdns
  • Chrome: chrome://net-internals/#dns → Clear host cache

3. Switch to a Public DNS Server

Change your DNS to Cloudflare (1.1.1.1) or Google (8.8.8.8). This resolves most cases where the probe is stuck waiting on an unresponsive ISP DNS server.

4. Reset Chrome Network State

Go to chrome://net-internals/#sockets → Flush socket pools. Then go to chrome://net-internals/#dns → Clear host cache.

5. Restart Browser and Computer

If the issue persists, close Chrome entirely and reopen it. If still stuck, restart the device to clear all network state.

Frequently Asked Questions

How long should DNS_PROBE_STARTED take?

Normally a fraction of a second. If it persists for more than 2–3 seconds, Chrome is likely waiting for an unresponsive DNS server to time out. Switching to a faster DNS server will speed up this process.

Related Errors

  • DNS_PROBE_FINISHED_NXDOMAIN — domain does not exist.
  • DNS_PROBE_FINISHED_BAD_CONFIG — DNS misconfiguration.
  • DNS Server Not Responding — resolver offline.
  • ERR_NAME_NOT_RESOLVED — DNS resolution failed.
