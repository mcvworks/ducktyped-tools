NXDOMAIN — Non-Existent Domain

Last updated: March 8, 2026

NXDOMAIN is a DNS response code meaning the queried domain does not exist. It is a definitive "no such domain" answer from the authoritative nameserver.

You might see this error as:

  • NXDOMAIN
  • Non-Existent Domain
  • RCODE 3
  • Domain does not exist
  • No such domain
  • DNS name does not exist

What Does NXDOMAIN Mean?

DNS response codes (RCODEs) tell you the result of a DNS query. NXDOMAIN (RCODE 3) is the authoritative DNS server's way of saying: "I am responsible for this domain's zone, and I confirm no records exist for this name."

This is different from a timeout or error — it is a positive answer that the domain does not exist. Browsers display this as DNS_PROBE_FINISHED_NXDOMAIN or "Server Not Found."

Common Causes

  • Domain never registered — the domain name has never been registered with a registrar.
  • Domain expired — the registration lapsed and DNS records were removed.
  • Typo in the domain name — visiting goggle.com instead of google.com.
  • Subdomain does not exist — accessing app.example.com when no such DNS record is configured.
  • Recent domain deletion — the domain was deleted or not renewed and DNS has propagated the removal.
  • DNS propagation — a new domain or record change has not yet reached all resolvers.
  • ISP DNS filtering — your ISP is returning NXDOMAIN for domains they have blocked.

Diagnosing NXDOMAIN

Is it just you, or everyone?

Use the DNS Lookup tool to query the domain from multiple resolvers. If all resolvers return NXDOMAIN, the domain genuinely does not exist (or has expired). If only your resolver returns NXDOMAIN while others resolve it, the issue is with your resolver or ISP filtering.

Check Domain Expiry

Use the WHOIS Lookup to verify the domain is registered and has not expired. An expired domain will show either no WHOIS data or a past expiry date.

Test with Different DNS Servers

nslookup example.com 1.1.1.1
nslookup example.com 8.8.8.8

If either resolves successfully, try switching your system's DNS to that server.

NXDOMAIN in Email

NXDOMAIN also affects email. If you send email to a domain that returns NXDOMAIN for MX record lookups, the mail will bounce with an NXDOMAIN error. This is a common cause of email delivery failures for mistyped or expired recipient domains.

Related Tools

  • DNS Lookup — query DNS from multiple resolvers to check if NXDOMAIN is universal.
  • WHOIS Lookup — check domain registration and expiry status.

Frequently Asked Questions

Why do some DNS servers return NXDOMAIN while others resolve the domain?

Possible reasons: DNS propagation delay (the record exists but has not reached that resolver yet), ISP-level filtering on one resolver, or DNSSEC-related blocking on a validating resolver for a domain with invalid signatures.

Can I register an NXDOMAIN to use it?

If the domain is genuinely unregistered, yes — you can register it through a domain registrar. Check current availability and pricing at any registrar.

Related Errors

  • DNS_PROBE_FINISHED_NXDOMAIN — browser error for NXDOMAIN.
  • SERVFAIL — DNS server error (not a definitive "no such domain").
  • DNS Lookup Failed — generic DNS failure.
  • ERR_NAME_NOT_RESOLVED — Chrome DNS failure.
