DNS Lookup Failed

Last updated: March 8, 2026

This error means the browser could not obtain a valid IP address for the domain. The DNS query did not return a usable result.

You might see this error as:

  • DNS lookup failed
  • getaddrinfo ENOTFOUND
  • DNS resolution failed
  • Could not resolve host
  • Name resolution failed

What Does This Error Mean?

"DNS Lookup Failed" is a generic description covering any situation where a DNS query does not return a valid A or AAAA record for the requested hostname. This differs from more specific errors like DNS_PROBE_FINISHED_NXDOMAIN (which confirms the domain does not exist) — "DNS Lookup Failed" can occur for several different underlying reasons.

Common Causes

  • Domain does not exist or has expired — the domain has no DNS records.
  • DNS server is down — the configured resolver is unreachable.
  • DNS server returned an error — SERVFAIL or REFUSED response from the authoritative server.
  • Stale or corrupted DNS cache — your device has a cached negative response.
  • No A or AAAA record configured — the domain is registered but has no address records.
  • DNS propagation not complete — recent DNS changes have not yet reached your resolver.
  • ISP DNS filtering — your ISP is blocking the domain at the DNS level.

How to Fix It

1. Check the Domain's DNS Records

Use the DNS Lookup tool to query the domain directly. If no A records are returned, the domain is either misconfigured or does not exist.

2. Flush Your DNS Cache

  • Windows: ipconfig /flushdns
  • macOS: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
  • Chrome: chrome://net-internals/#dns → Clear host cache

3. Try a Different DNS Server

Switch to Cloudflare (1.1.1.1) or Google (8.8.8.8) DNS to rule out an ISP DNS issue.

4. Check Domain Registration

Use the WHOIS Lookup to verify the domain is registered and has not expired.

5. Wait for DNS Propagation

If DNS records were recently updated, changes can take up to 48 hours to fully propagate. Use the DNS Lookup tool against multiple resolvers to check propagation status.

Frequently Asked Questions

How do I know if the problem is my DNS server or the domain's DNS?

Test the same domain against multiple DNS servers: nslookup domain.com 1.1.1.1 and nslookup domain.com 8.8.8.8. If both fail, the domain has no records or is blocked globally. If one works and another does not, the failing server is the issue.

Can a website be up but DNS lookup fail?

Yes — if a domain's DNS records are deleted or expired, no one can resolve it regardless of whether the web server is running. The web server itself may be healthy, but without DNS records, browsers cannot find it.

Related Errors

  • DNS_PROBE_FINISHED_NXDOMAIN — domain confirmed nonexistent.
  • DNS Server Not Responding — DNS server offline.
  • SERVFAIL — DNS server error response.
  • ERR_NAME_NOT_RESOLVED — Chrome DNS resolution failure.
