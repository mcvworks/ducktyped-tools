DNS SERVFAIL (Server Failure)

Last updated: March 8, 2026

SERVFAIL is a DNS response code meaning the server encountered an internal error and could not complete your query. It can stem from DNSSEC failures, nameserver problems, or resolver timeouts.

You might see this error as:

  • SERVFAIL
  • Server Failure
  • RCODE 2
  • DNS server failure
  • DNS SERVFAIL
  • Server failed to complete the DNS request

What Does SERVFAIL Mean?

DNS response codes (RCODEs) communicate the result of a DNS query. SERVFAIL (RCODE 2) means the DNS server could not process the query due to an internal failure. Unlike NXDOMAIN — which definitively says the domain does not exist — SERVFAIL is an error condition that may be temporary.

The key question with SERVFAIL is: did the resolver fail (your ISP's or Cloudflare's DNS) or did the authoritative nameserver for the domain fail?

Common Causes

  • DNSSEC validation failure — the DNS record signature is invalid or expired, and the resolver enforces DNSSEC. This is the most common cause.
  • Authoritative nameserver is down — the domain's authoritative nameservers are unreachable or offline.
  • Resolver timeout — the recursive resolver timed out trying to reach the authoritative nameserver.
  • Zone configuration error — malformed DNS zone data on the authoritative nameserver.
  • Nameserver delegation mismatch — the DNS registrar and the authoritative server have conflicting NS records.
  • Resolver internal error — a bug or overload in the recursive resolver itself.

How to Fix It

For Visitors

1. Try a Different DNS Resolver

Test whether the issue is with your current resolver. Switch to Cloudflare (1.1.1.1) or Google (8.8.8.8) and retry. If one resolver returns SERVFAIL but another resolves successfully, the issue is with that specific resolver.

2. Check with a DNS Tool

Use the DNS Lookup tool to query the domain. Alternatively, use nslookup:

nslookup example.com 1.1.1.1
nslookup example.com 8.8.8.8

For Domain Owners

3. Check DNSSEC Configuration

A mismatched or expired DNSSEC key is the most common cause of SERVFAIL on validating resolvers. Check your DNSSEC key status at your registrar and ensure DS records match your authoritative nameserver's DNSKEY records.

4. Verify Nameserver Availability

Confirm all authoritative nameservers listed in your zone delegation are online and responding correctly.

5. Check Zone File for Errors

Validate your zone file for syntax errors. Most DNS server software (BIND, PowerDNS) has a zone file check command.

Related Tools

  • DNS Lookup — query DNS records from multiple resolvers.
  • WHOIS Lookup — check nameserver delegation.

Frequently Asked Questions

Is SERVFAIL permanent?

Not necessarily. SERVFAIL can be transient (resolver overload, temporary nameserver issue) or persistent (DNSSEC misconfiguration). If it persists across multiple resolvers and time periods, it indicates a configuration problem on the domain's nameservers.

Can SERVFAIL affect DNSSEC-enabled resolvers but not others?

Yes. If a domain has invalid DNSSEC signatures, resolvers that enforce DNSSEC validation (like Cloudflare 1.1.1.1) will return SERVFAIL, while resolvers that do not validate DNSSEC (some ISP resolvers) may still resolve the domain successfully. This is intentional — DNSSEC validation prevents accepting potentially tampered responses.

Related Errors

  • NXDOMAIN — domain definitively does not exist.
  • DNS Server Not Responding — DNS server offline.
  • DNS Lookup Failed — generic DNS failure.
