DNS_PROBE_FINISHED_NO_INTERNET

Last updated: March 8, 2026

This error means Chrome's DNS diagnostic confirmed that your device has no internet connection. All DNS queries are failing because you are offline or your internet access is blocked.

You might see this error as:

  • DNS_PROBE_FINISHED_NO_INTERNET
  • No internet DNS error
  • DNS probe no internet
  • This site can't be reached no internet

What Does This Error Mean?

After a DNS lookup fails, Chrome runs a diagnostic probe to determine the root cause. DNS_PROBE_FINISHED_NO_INTERNET is the result when Chrome concludes that the problem is not a specific domain or DNS server issue — the device simply has no internet connectivity at all.

This is distinct from DNS_PROBE_FINISHED_NXDOMAIN (a specific domain does not exist) and DNS_PROBE_FINISHED_BAD_CONFIG (DNS misconfiguration). NO_INTERNET is the most fundamental error: nothing can be reached.

Common Causes

  • No Wi-Fi or ethernet connection — the device is not connected to any network.
  • Router or modem offline — the network is connected but has no upstream internet access.
  • ISP outage — your internet service provider is experiencing a disruption.
  • VPN kill switch — a VPN's kill switch is blocking all traffic because the VPN connection dropped.
  • Firewall blocking all outbound traffic — overly restrictive firewall rules.
  • Unauthenticated captive portal — on hotel or public Wi-Fi, you need to log in through a portal page.
  • Network adapter disabled — the Wi-Fi or ethernet adapter has been turned off.

How to Fix It

1. Check Network Connection

Verify your device is connected to a network (check the Wi-Fi icon or ethernet status). Disconnect and reconnect to refresh the connection.

2. Restart Router and Modem

Power cycle both devices. Unplug the modem first, wait 30 seconds, plug it back in, wait for it to connect, then power on the router.

3. Test with Another Device

Check if other devices on the same network have internet access. If they do, the issue is specific to your device. If none do, the problem is with the router or ISP.

4. Flush DNS Cache

  • Windows: ipconfig /flushdns
  • macOS: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder

5. Check VPN

If using a VPN with a kill switch, the VPN may have disconnected. Try disabling the VPN entirely to restore internet access.

6. Reset Network Settings (Windows)

netsh int ip reset
netsh winsock reset
ipconfig /release
ipconfig /renew

7. Authenticate Captive Portal

On public or hotel Wi-Fi, open a browser and navigate to any HTTP site (not HTTPS). The portal login page should appear. Complete authentication before retrying.

Frequently Asked Questions

Is DNS_PROBE_FINISHED_NO_INTERNET the same as being offline?

Essentially yes. Chrome's probe determined that DNS queries cannot succeed because there is no internet connectivity — either your device is offline, the network has no internet access, or all traffic is being blocked.

Why does this happen after waking from sleep?

Some network adapters briefly lose connectivity when a computer wakes from sleep. Waiting a few seconds or manually reconnecting to Wi-Fi usually resolves it.

Related Errors

  • ERR_INTERNET_DISCONNECTED — no internet connection (browser error).
  • DNS_PROBE_STARTED — diagnostic in progress.
  • DNS_PROBE_FINISHED_BAD_CONFIG — DNS misconfiguration.
  • ERR_NAME_NOT_RESOLVED — DNS resolution failed.
