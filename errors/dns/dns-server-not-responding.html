DNS Server Not Responding

Last updated: March 8, 2026

This error means your device can reach the network but the DNS server it is configured to use is offline, unreachable, or not responding to queries.

You might see this error as:

  • DNS server not responding
  • DNS server is not responding
  • Cannot reach DNS server
  • DNS server unreachable
  • DNS server down

What Does This Error Mean?

When you type a domain name into your browser, your device contacts a DNS resolver to translate it into an IP address. "DNS Server Not Responding" means that resolver is not answering. Your internet connection itself may be fine — you might even be able to reach sites by IP address directly — but domain name resolution is broken.

Common Causes

  • ISP DNS server outage — your ISP's DNS servers are experiencing downtime or maintenance.
  • Router DNS cache corruption — the router's DNS forwarder has a corrupt state.
  • Misconfigured DNS settings — the DNS server IP in your network adapter settings is wrong or unreachable.
  • Firewall blocking DNS port — UDP port 53 is being blocked by a local or network firewall.
  • VPN DNS configuration — VPN overriding DNS with a server that is unreachable when VPN disconnects.
  • DNS service stopped on router — the router's DNS forwarder process has crashed.

How to Fix It

1. Switch to a Public DNS Server

The fastest fix is to change your DNS server to a reliable public resolver:

  • Cloudflare: 1.1.1.1 and 1.0.0.1
  • Google: 8.8.8.8 and 8.8.4.4
  • Quad9: 9.9.9.9

On Windows: Settings → Network & Internet → Change adapter options → your connection → Properties → IPv4 → Use the following DNS server addresses.

2. Restart Your Router

Power cycle your router to reset its DNS forwarder. Wait 30 seconds before turning it back on.

3. Flush DNS Cache

  • Windows: ipconfig /flushdns
  • macOS: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
  • Linux: sudo systemd-resolve --flush-caches

4. Check Firewall Rules

Verify that UDP port 53 is not blocked by your firewall. DNS queries use UDP 53 by default (TCP 53 for large responses).

5. Test DNS with nslookup

Test DNS resolution directly:

nslookup example.com 1.1.1.1

If this works but normal browsing does not, your configured DNS server is the problem.

Frequently Asked Questions

Can I use a DNS server other than my ISP's?

Yes, and it is often beneficial. Public DNS servers like Cloudflare (1.1.1.1) and Google (8.8.8.8) are typically faster and more reliable than ISP DNS servers, and they support DNSSEC and DNS-over-HTTPS for better privacy.

How do I know if my ISP's DNS is down?

Try pinging your ISP's DNS server directly: ping your-dns-server-ip. If it does not respond, the server is down or unreachable. Switching to a public DNS server is the fastest workaround.

Related Errors

  • ERR_NAME_NOT_RESOLVED — DNS resolution failure in Chrome.
  • DNS Lookup Failed — generic DNS lookup failure.
  • DNS_PROBE_FINISHED_NXDOMAIN — domain does not exist.
  • DNS_PROBE_FINISHED_BAD_CONFIG — DNS misconfiguration detected.
