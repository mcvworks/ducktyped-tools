DNS_PROBE_POSSIBLE

Last updated: March 8, 2026

Chrome is investigating a possible DNS resolution issue

You might see this error as:

  • DNS_PROBE_POSSIBLE
  • DNS probe possible error
  • Possible DNS issue

What Does This Error Mean?

DNS_PROBE_POSSIBLE is a transient Chrome error indicating that the browser suspects a DNS resolution problem but has not confirmed it yet. Chrome's internal DNS probe mechanism is running diagnostics to determine whether the failure is caused by DNS misconfiguration, network issues, or a temporary glitch. This error often resolves itself within seconds, but persistent occurrences indicate an underlying network or DNS problem.

Common Causes

  • Intermittent network connectivity — Brief network dropouts or unstable Wi-Fi connections can cause DNS queries to fail sporadically. Chrome detects the failure and begins probing to determine whether the DNS infrastructure is the root cause.
  • DNS server under load or slow to respond — The configured DNS server is taking too long to respond, causing Chrome to suspect a DNS failure while the query is still in progress.
  • VPN or proxy connection instability — A VPN or proxy that routes DNS queries through a tunnel may experience momentary disruptions, causing Chrome to flag a possible DNS issue during the reconnection window.
  • DNS cache transition — Chrome's internal DNS cache is being rebuilt after a network change or cache flush, and lookups performed during this transition period may trigger the probe.

How to Fix It

1. Wait and retry

This error is often transient. Wait a few seconds and reload the page. Chrome's DNS probe will complete its diagnostics and either resolve the issue or report a more specific error.

2. Flush Chrome's internal DNS cache

Navigate to chrome://net-internals/#dns and click 'Clear host cache'. This forces Chrome to perform fresh DNS lookups rather than relying on potentially stale cached entries.

3. Check your network connection

Verify that your network connection is stable. If you are on Wi-Fi, try moving closer to the router or switching to a wired connection. Run a quick connectivity test to confirm internet access.

# Test basic connectivity
ping -c 4 8.8.8.8

# Test DNS resolution
nslookup google.com

4. Switch DNS servers

If the error persists, your current DNS server may be unreliable. Switch to a public DNS provider for more consistent resolution.

# Recommended public DNS servers
# Google DNS: 8.8.8.8, 8.8.4.4
# Cloudflare DNS: 1.1.1.1, 1.0.0.1
# Quad9: 9.9.9.9, 149.112.112.112

Frequently Asked Questions

Is DNS_PROBE_POSSIBLE a serious error?

No. It is a diagnostic state indicating Chrome is still investigating the issue. It often resolves on its own. If it persists or transitions to a more specific error like DNS_PROBE_FINISHED_NXDOMAIN, follow the troubleshooting steps for that specific error.

Why do I see this error only on certain websites?

Some domains may have slower DNS servers or be hosted on nameservers that are geographically distant. The extra latency can trigger Chrome's probe mechanism while faster domains resolve normally.

Does this error appear in other browsers?

DNS_PROBE_POSSIBLE is specific to Chrome's DNS probing system. Other browsers may show different error messages or simply display a generic connection error for the same underlying DNS issue.
