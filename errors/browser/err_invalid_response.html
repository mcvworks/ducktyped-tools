ERR_INVALID_RESPONSE

Last updated: March 8, 2026

Server sent a response the browser cannot parse

You might see this error as:

  • net::ERR_INVALID_RESPONSE
  • ERR_INVALID_RESPONSE Chrome
  • Invalid response received
  • This page isn't working

What Does This Error Mean?

ERR_INVALID_RESPONSE occurs when the server sends a response that does not conform to the HTTP specification and the browser cannot parse it. This typically means the response headers are malformed, the status line is missing or corrupt, or the server is speaking a different protocol than expected. It is a catch-all error for responses that are syntactically invalid at the HTTP level.

Common Causes

  • Malformed HTTP response headers — The server is sending response headers that violate HTTP syntax rules, such as missing the status line, using invalid characters in header names, or sending improperly terminated headers.
  • Server sending non-HTTP data — The server process is responding with a protocol other than HTTP (such as raw TCP data or a different application protocol) on the expected HTTP port.
  • Proxy returning garbage data — A forward or reverse proxy is corrupting the response by mixing data from different connections, truncating headers, or injecting non-HTTP content.
  • Server application crash mid-response — The server-side application crashed while writing the response headers, leaving the output in an incomplete and unparseable state.

How to Fix It

1. Check server logs for errors

Examine the web server and application error logs for crashes, segmentation faults, or exceptions that occur when the failing URL is requested. The root cause is almost always server-side.

2. Test with curl for detailed output

Use curl with verbose output to see exactly what the server is sending. This will show the raw response including any malformed headers or unexpected data.

curl -v https://example.com/problematic-path

3. Restart the web server

Restart the web server process (Nginx, Apache, Node.js, etc.) to clear any corrupted state. If the server application is crashing, fix the underlying application error.

4. Bypass proxy or VPN

If you are using a proxy or VPN, bypass it temporarily to test whether the intermediary is corrupting the response. Connect directly to the server to isolate the issue.

Frequently Asked Questions

What is the difference between ERR_INVALID_RESPONSE and a 500 error?

A 500 error is a valid HTTP response indicating a server error. ERR_INVALID_RESPONSE means the server did not send a valid HTTP response at all — the browser cannot even parse what the server sent.

Can antivirus software cause ERR_INVALID_RESPONSE?

Yes, antivirus software that intercepts and inspects network traffic can sometimes corrupt HTTP responses, particularly when it fails to properly re-inject modified content.

Why does this error only happen on certain pages?

Different pages may be handled by different server-side code paths. The error typically occurs when a specific code path produces malformed output or crashes during response generation.
