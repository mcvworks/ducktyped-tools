ERR_BLOCKED_BY_CLIENT

Last updated: March 8, 2026

This error means a browser extension intercepted and blocked a network request before it left your browser. Usually caused by ad blockers or privacy extensions.

You might see this error as:

  • net::ERR_BLOCKED_BY_CLIENT
  • ERR_BLOCKED_BY_CLIENT Chrome
  • Blocked by ad blocker
  • ERR_BLOCKED_BY_CLIENT uBlock
  • Request blocked by extension

What Does This Error Mean?

ERR_BLOCKED_BY_CLIENT is distinct from server-side blocks like 403 Forbidden. The request never reached the server — it was cancelled by a browser extension or client-side rule before any connection was made.

Chrome extensions can intercept and block any network request using the webRequest or declarativeNetRequest API. This is how ad blockers work — they cancel requests to known tracking and advertising domains before the browser even opens a connection.

Common Causes

  • Ad blockers — uBlock Origin, AdBlock, AdBlock Plus blocking a script, image, or API call.
  • Privacy extensions — Privacy Badger, Ghostery, Disconnect blocking a tracker.
  • Corporate security extensions — endpoint security tools enforcing a content policy.
  • Parental control extensions — blocking certain content categories.
  • Custom filter lists — a user-added block rule that matches the resource URL.
  • Anti-malware browser protection — blocking a URL flagged as suspicious.

How to Fix It

For Users

1. Test in Incognito Mode

Open the page in an incognito/private window (Ctrl+Shift+N). Incognito mode disables most extensions by default. If the page loads, an extension is the cause.

2. Identify the Blocking Extension

Open Chrome DevTools (F12) → Network tab → reload the page → look for requests with status "blocked" or "(blocked:extension)". The initiator column may name the responsible extension.

3. Disable Extensions One by One

Go to chrome://extensions/ and toggle off extensions one at a time, reloading the page each time to find the culprit.

4. Whitelist the Site in Your Ad Blocker

Once you identify the blocking extension, add the affected site to its whitelist or disable it on that site using the extension's toolbar icon.

For Developers

5. Avoid Common Ad/Tracking Patterns in URLs

Ad blockers use filter lists that match URLs containing patterns like /ads/, /analytics/, /track, or /pixel. Rename legitimate API endpoints that match these patterns to avoid accidental blocks.

Frequently Asked Questions

Can ERR_BLOCKED_BY_CLIENT appear for the entire page?

Usually it affects individual resources (scripts, images, API calls) rather than the entire page. If the main document URL is blocked, the whole page will fail to load. If only a sub-resource is blocked, the page may load partially.

Is ERR_BLOCKED_BY_CLIENT always caused by extensions?

In Chrome, yes. Unlike 403 Forbidden (server block) or firewall rules, this specific error code indicates the block happened in the browser itself via an extension API.

My site works on other browsers but not Chrome — could ERR_BLOCKED_BY_CLIENT be the cause?

If you have extensions in Chrome that you do not have in other browsers, yes. The extension is blocking a resource that the other browsers allow. Test in Chrome with extensions disabled to confirm.

Related Errors

  • 403 Forbidden — server-side block, not client-side.
  • 401 Unauthorized — authentication required.
  • ERR_CONNECTION_REFUSED — server refused the connection.
