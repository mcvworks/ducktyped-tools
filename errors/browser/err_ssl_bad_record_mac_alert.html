ERR_SSL_BAD_RECORD_MAC_ALERT

Last updated: March 8, 2026

SSL/TLS record has an incorrect MAC (message authentication code)

You might see this error as:

  • ERR_SSL_BAD_RECORD_MAC_ALERT
  • SSL bad record MAC
  • SSL handshake error
  • bad record MAC alert

What Does This Error Mean?

ERR_SSL_BAD_RECORD_MAC_ALERT occurs when the message authentication code (MAC) on an SSL/TLS record does not match the expected value. This means the encrypted data was altered or corrupted during transmission, which can indicate network-level data corruption, faulty network hardware, or a man-in-the-middle attack. The browser terminates the connection to protect against tampered data.

Common Causes

  • Network data corruption — Faulty network hardware such as a bad network interface card, damaged Ethernet cable, or malfunctioning switch is corrupting packets in transit, altering the encrypted payload.
  • TLS version or cipher mismatch — The client and server negotiated a cipher suite that one side does not correctly implement, leading to MAC calculation errors during the handshake or data transfer.
  • MTU or packet fragmentation issues — Incorrect MTU settings on the network path are causing TLS records to be fragmented and reassembled incorrectly, resulting in MAC verification failures.
  • Firewall or security appliance interference — A firewall, IDS, or SSL inspection appliance is modifying encrypted traffic without properly re-encrypting it, causing MAC validation to fail.

How to Fix It

1. Test with a different network

Switch to a different network connection (mobile hotspot, different Wi-Fi, or wired connection) to determine whether the issue is caused by network hardware or configuration on your current network.

2. Disable SSL inspection

If your network uses SSL inspection (common in corporate environments), temporarily disable it or add an exception for the affected domain to see if it resolves the error.

3. Lower the MTU size

Reduce the network MTU to avoid fragmentation issues with TLS records. On Windows, use netsh to set a lower MTU value.

netsh interface ipv4 set subinterface "Ethernet" mtu=1400 store=persistent

4. Update network drivers and firmware

Update your network adapter drivers and router firmware, as bugs in network hardware can cause bit-level corruption that triggers MAC validation failures.

Frequently Asked Questions

Is ERR_SSL_BAD_RECORD_MAC_ALERT a security threat?

It can indicate a man-in-the-middle attack, but it is more commonly caused by network hardware issues or misconfigured SSL inspection. The browser correctly blocks the connection in all cases to protect you.

Why does this error appear intermittently?

Intermittent occurrences usually point to flaky network hardware or congested network paths. The corruption happens randomly depending on which physical path the packets take.
