ERR_SSL_VERSION_OR_CIPHER_MISMATCH

Last updated: March 8, 2026

This error means the browser and server could not agree on a TLS protocol version or cipher suite. It is almost always a server-side configuration problem.

You might see this error as:

  • ERR_SSL_VERSION_OR_CIPHER_MISMATCH
  • SSL version or cipher mismatch
  • This site can't provide a secure connection
  • Unsupported protocol
  • Client and server don't support a common SSL protocol version

What Does This Error Mean?

When your browser connects to an HTTPS site, it negotiates which TLS version and cipher suite to use with the server. ERR_SSL_VERSION_OR_CIPHER_MISMATCH means no mutually supported combination could be found.

Modern browsers (Chrome 84+, Firefox 74+, Safari 14+) have removed support for TLS 1.0 and TLS 1.1 as well as all RC4 and export-grade ciphers. If a server only supports these deprecated options, visitors using modern browsers will see this error.

Common Causes

  • Server only supports TLS 1.0 or 1.1 — these versions are disabled in all major browsers.
  • Deprecated cipher suites — RC4, DES, 3DES, and export ciphers are blocked by browsers.
  • SSL certificate hostname mismatch — the certificate is issued for a different domain than the one being accessed.
  • Outdated server software — old versions of nginx, Apache, or IIS may not support modern TLS.
  • Antivirus SSL interception — security software may intercept SSL with an outdated cipher configuration.
  • Legacy embedded devices — routers, IoT devices, or intranet appliances may only support old TLS.

How to Fix It

For Site Owners

1. Enable TLS 1.2 and TLS 1.3

In nginx, update your ssl_protocols directive:

ssl_protocols TLSv1.2 TLSv1.3;

In Apache, update SSLProtocol:

SSLProtocol -all +TLSv1.2 +TLSv1.3

2. Update Your Cipher Suite

Remove weak ciphers and use a modern suite. Mozilla's SSL Config Generator provides up-to-date recommendations for all major web servers.

3. Verify Your Certificate Hostname

Ensure your SSL certificate covers the exact hostname being accessed, including www vs non-www variants. Use the SSL Checker to inspect your certificate.

For Visitors

4. Try a Different Browser

If the site works in an older browser or incognito mode, the issue may be with your browser's configuration rather than the server.

5. Check Antivirus SSL Scanning

Some antivirus programs intercept HTTPS traffic. Temporarily disabling SSL scanning in your security software may resolve the error for that session.

Frequently Asked Questions

Which TLS versions should my server support?

Support TLS 1.2 and TLS 1.3 only. TLS 1.0 and 1.1 are deprecated and disabled in all major browsers. TLS 1.3 is faster and more secure and should be preferred.

Does this error mean my site has been hacked?

No. This is a configuration mismatch between the server's supported protocols and the browser's requirements. It is not a sign of a security breach — it is the browser protecting users from connecting over an insecure protocol.

Can I bypass ERR_SSL_VERSION_OR_CIPHER_MISMATCH?

Not in standard browsers. This is a hard block for security reasons. The correct fix is to update the server's TLS configuration.
