ERR_NAME_NOT_RESOLVED

Last updated: March 8, 2026

This error means the browser could not resolve the domain name — DNS returned no usable result. Here is what causes it and how to fix it.

You might see this error as:

  • net::ERR_NAME_NOT_RESOLVED
  • ERR_NAME_NOT_RESOLVED Chrome
  • This site can't be reached
  • DNS address could not be found
  • Server DNS address could not be found

Where This Error Occurs

What Does This Error Mean?

When you enter a URL, your browser asks a DNS resolver to convert the domain name into an IP address. ERR_NAME_NOT_RESOLVED appears when that lookup fails entirely — the DNS server either has no record for the domain or could not be reached in time.

This differs slightly from DNS_PROBE_FINISHED_NXDOMAIN: that error means the server positively confirmed the domain does not exist, while ERR_NAME_NOT_RESOLVED can also occur when the DNS server itself is unreachable or times out.

Common Causes

  • Mistyped URL — the most frequent cause. Verify spelling and the TLD (.com, .net, .org).
  • DNS server unreachable — your configured DNS server is offline or not responding.
  • Stale DNS cache — old or corrupted records cached on your device or router.
  • Domain does not exist — the domain was never registered, has expired, or was deleted.
  • No internet connection — DNS queries cannot leave your device if you are offline.
  • Firewall or security software blocking DNS — antivirus or parental controls may be intercepting DNS queries.
  • VPN DNS leak or misconfiguration — VPN may be routing DNS through an unreachable resolver.

How to Fix It

1. Verify the URL

Check the address bar for typos, missing letters, or the wrong domain extension. Try searching for the site in a search engine if you are unsure of the exact address.

2. Flush DNS Cache

  • Windows: ipconfig /flushdns in an elevated Command Prompt
  • macOS: sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
  • Linux: sudo systemd-resolve --flush-caches
  • Chrome: chrome://net-internals/#dns → Clear host cache

3. Switch to a Public DNS Server

Change your DNS to a reliable public resolver in your network adapter or router settings:

  • Cloudflare: 1.1.1.1 / 1.0.0.1
  • Google: 8.8.8.8 / 8.8.4.4
  • Quad9: 9.9.9.9

4. Check Your Internet Connection

Open another site or try pinging a known IP (ping 1.1.1.1) to confirm whether you have network access at all.

5. Restart Router and Modem

Power cycle your router. Wait 30 seconds before turning it back on to clear any cached DNS state.

6. Disable VPN or Security Software Temporarily

Disconnect your VPN or temporarily disable antivirus DNS filtering to see if they are the cause.

Frequently Asked Questions

Is ERR_NAME_NOT_RESOLVED the same on all browsers?

Chrome and Edge display this specific error code. Firefox shows "Server Not Found" and Safari shows "Safari Can't Find the Server" — but all indicate the same underlying DNS resolution failure.

Why does ERR_NAME_NOT_RESOLVED happen on mobile but not desktop?

Mobile devices may use different DNS servers (via cellular carrier) than your Wi-Fi network. If one works and the other does not, the issue is likely with a specific DNS server rather than the domain itself.

Can a website be up but still trigger this error?

Yes. If the domain's DNS records are valid but your local DNS server has a corrupted cache entry, you will see this error even though the site is reachable for everyone else. Flushing your DNS cache usually resolves it.

Related Errors

  • DNS_PROBE_FINISHED_NXDOMAIN — DNS server confirmed the domain does not exist.
  • DNS Server Not Responding — DNS server is offline or unreachable.
  • DNS Lookup Failed — generic DNS resolution failure.
  • ERR_INTERNET_DISCONNECTED — no network connection at all.
