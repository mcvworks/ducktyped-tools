ERR_TUNNEL_CONNECTION_FAILED

Last updated: March 8, 2026

Failed to establish an HTTPS tunnel through a proxy server

You might see this error as:

  • net::ERR_TUNNEL_CONNECTION_FAILED
  • ERR_TUNNEL_CONNECTION_FAILED Chrome
  • Tunnel connection failed
  • Proxy tunnel failed

What Does This Error Mean?

ERR_TUNNEL_CONNECTION_FAILED occurs when the browser attempts to create an HTTPS tunnel through a proxy server using the HTTP CONNECT method, but the proxy rejects or fails to establish the tunnel. This is specific to HTTPS traffic through proxies — the browser needs to create an encrypted tunnel through the proxy to the destination server, and this tunnel setup is failing. The proxy may be refusing the CONNECT request, timing out, or returning an error.

Common Causes

  • Proxy blocks CONNECT method — The proxy server is configured to deny HTTP CONNECT requests, which are required for tunneling HTTPS traffic. Some restrictive proxies only allow plain HTTP and block encrypted tunnels.
  • Proxy authentication required — The proxy requires authentication credentials (username and password) for CONNECT requests, and the browser either is not sending credentials or is sending incorrect ones.
  • Proxy denies the destination host or port — The proxy has an access control list that blocks tunneling to specific destination hosts or ports, preventing the encrypted connection from being established.
  • Proxy server overloaded or misconfigured — The proxy server is overloaded and cannot handle additional tunnel connections, or its configuration for handling CONNECT requests is broken.

How to Fix It

1. Verify proxy authentication credentials

Ensure your proxy authentication credentials are correct. Update the username and password in your browser or system proxy settings if they have changed.

2. Use a direct connection for HTTPS

Configure a proxy exception for HTTPS traffic if your network allows direct connections for encrypted traffic. Add exceptions in your proxy bypass list.

# Windows: Set proxy bypass list
netsh winhttp set proxy proxy-server="proxy.example.com:8080" bypass-list="*.example.com;*.secure-site.com"

3. Contact network administrator

If you are on a managed network, ask your IT department to allow CONNECT requests through the proxy for the blocked destination. They may need to update the proxy's access control list.

4. Try a different proxy or VPN

If the current proxy blocks HTTPS tunneling, use a different proxy server or a VPN that properly supports encrypted traffic forwarding.

Frequently Asked Questions

Why does this error only affect HTTPS sites?

HTTP traffic can flow through a proxy directly. HTTPS traffic requires a tunnel (via HTTP CONNECT) so the proxy cannot see the encrypted content. This error occurs when the tunnel creation fails.

Is ERR_TUNNEL_CONNECTION_FAILED the same as ERR_PROXY_CONNECTION_FAILED?

No. ERR_PROXY_CONNECTION_FAILED means the browser cannot connect to the proxy at all. ERR_TUNNEL_CONNECTION_FAILED means the browser connected to the proxy, but the proxy refused to create an HTTPS tunnel.
