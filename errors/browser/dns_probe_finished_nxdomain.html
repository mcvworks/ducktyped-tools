DNS_PROBE_FINISHED_NXDOMAIN

Last updated: March 8, 2026

This error means the browser could not resolve the domain name — the DNS server responded that the domain does not exist. Here is what causes it and how to fix it.

You might see this error as:

  • dns_probe_finished_nxdomain
  • ERR_NAME_NOT_RESOLVED
  • This site can't be reached
  • DNS address could not be found
  • Server DNS address could not be found
  • net::ERR_NAME_NOT_RESOLVED
  • DNS_PROBE_FINISHED_NXDOMAIN Chrome

Where This Error Occurs

What Does This Error Mean?

NXDOMAIN stands for Non-Existent Domain. When you type a URL into your browser, it sends a DNS query to translate the domain name (like example.com) into an IP address. If the DNS server responds that the domain has no records, your browser displays this error instead of loading the page.

This is different from a connection timeout — the DNS server actively replied that the domain cannot be found. The domain either does not exist, has been mistyped, has expired, or its DNS records are missing or misconfigured.

Common Causes

  • Mistyped URL — the most common cause. Double-check the address for spelling mistakes.
  • Stale DNS cache — your device or router may have cached an old or invalid record.
  • Domain expired — the domain owner did not renew registration, and the domain has been removed from DNS.
  • DNS propagation delay — recent DNS changes have not yet propagated to all resolvers worldwide.
  • Incorrect DNS server — your device is using a DNS server that cannot resolve the domain.
  • Missing DNS records — the domain exists but has no A or AAAA record pointing to a server.
  • ISP DNS filtering — your ISP may be blocking the domain at the DNS level.
  • VPN or proxy interference — a VPN may be routing DNS queries through a resolver that cannot reach the domain.

How to Fix It

1. Check the URL

Verify the address is spelled correctly. Look for common mistakes: missing letters, wrong TLD (e.g., .net instead of .com), or extra characters.

2. Flush Your DNS Cache

Your device may have cached a stale or invalid DNS response. Clear it:

  • Windows: Open Command Prompt as administrator → ipconfig /flushdns
  • macOS: Open Terminal → sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
  • Linux: sudo systemd-resolve --flush-caches or restart the DNS service
  • Chrome: Go to chrome://net-internals/#dns → click Clear host cache

3. Try a Different DNS Server

Your current DNS server may not be resolving the domain correctly. Try switching to a public DNS server:

  • Cloudflare: 1.1.1.1 and 1.0.0.1
  • Google: 8.8.8.8 and 8.8.4.4
  • Quad9: 9.9.9.9

Change DNS in your network adapter settings (Windows: Network & Internet → Change adapter options) or your router's admin panel.

4. Check the Domain's DNS Records

Use the duckTyped DNS Lookup tool to inspect the domain's records. If there are no A or AAAA records, the domain may be misconfigured or the server may be down.

5. Disable VPN or Proxy

If you are using a VPN, try disconnecting it. Some VPN configurations route DNS queries through servers that cannot resolve certain domains.

6. Restart Your Router

Your router maintains its own DNS cache. A restart clears it. Wait 30 seconds after powering off before turning it back on.

7. Check Domain Expiry

Use the WHOIS Lookup tool to check whether the domain registration has expired. An expired domain loses its DNS records.

Frequently Asked Questions

What does NXDOMAIN mean?

NXDOMAIN is a DNS response code meaning Non-Existent Domain. The authoritative nameserver confirmed that no records exist for the queried name. It is a definitive "does not exist" response, not a timeout.

Is this a problem on my end or the website's end?

It can be either. If only you are experiencing the error, it is likely a local issue (stale cache, wrong DNS server, ISP filtering). If the domain is down for everyone, the problem is on the website's end — expired domain, missing DNS records, or a misconfigured nameserver.

How long does DNS propagation take?

DNS changes typically propagate globally within a few minutes to 48 hours, depending on the TTL of the previous records. If you recently changed DNS settings, wait and try again later.
