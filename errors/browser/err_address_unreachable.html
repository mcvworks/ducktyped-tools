ERR_ADDRESS_UNREACHABLE

Last updated: March 8, 2026

IP address of the server is unreachable from the client

You might see this error as:

  • net::ERR_ADDRESS_UNREACHABLE
  • ERR_ADDRESS_UNREACHABLE Chrome
  • The server IP address could not be found
  • Address unreachable error

What Does This Error Mean?

ERR_ADDRESS_UNREACHABLE occurs when the browser resolves the domain name to an IP address but cannot establish a network connection to that address. This means DNS resolution succeeded but the IP address is not routable or accessible from the client's network. Common causes include the server being offline, incorrect DNS records pointing to the wrong IP, or network routing issues between the client and server.

Common Causes

  • Server is offline or shut down — The server at the resolved IP address is powered off, crashed, or undergoing maintenance, making it completely unreachable on the network.
  • DNS records point to wrong IP — The domain's DNS A or AAAA records contain an IP address that is no longer assigned to the server, such as after a server migration where DNS was not updated.
  • IP address is on a private or unreachable network — The resolved IP address is in a private range (like 10.x.x.x or 192.168.x.x) that is not accessible from the client's network, or is blocked by routing rules.
  • Network routing failure — There is a routing problem between the client and server, such as a broken BGP route, ISP outage, or misconfigured network gateway that prevents packets from reaching the destination.
  • Local firewall blocking outbound connections — A firewall on the client machine or local network is blocking outbound connections to the server's IP address or port, preventing any network traffic from reaching it.

How to Fix It

1. Verify the server is online

Use ping or an external monitoring service to confirm the server is up and responding to network traffic. If the server is down, it needs to be restarted.

2. Check DNS records for correct IP

Look up the domain's DNS records to verify they point to the correct and current server IP address. Update DNS if the records are stale.

nslookup example.com
# or
dig example.com A

3. Test network connectivity

Use traceroute to identify where the network path to the server fails. This helps determine if the issue is with your ISP, an intermediate network, or the destination.

tracert example.com   # Windows
traceroute example.com # Linux/macOS

4. Try a different network or VPN

Connect through a different network or VPN to determine if the issue is specific to your current network path. If it works on another network, the problem is with your local network or ISP.

Frequently Asked Questions

What is the difference between ERR_ADDRESS_UNREACHABLE and ERR_NAME_NOT_RESOLVED?

ERR_NAME_NOT_RESOLVED means DNS failed to find an IP address for the domain. ERR_ADDRESS_UNREACHABLE means DNS found an IP, but the browser cannot connect to that IP.

Can a website be unreachable from my location but reachable from others?

Yes. Network routing issues, regional ISP outages, or geo-blocking can make a server unreachable from specific locations while remaining accessible from others.

Does this error mean the website is permanently down?

Not necessarily. The server may be temporarily offline for maintenance, experiencing a network issue, or the DNS records may need to be updated. Try again later.
