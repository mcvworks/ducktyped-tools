ERR_PROXY_CONNECTION_FAILED

Last updated: March 8, 2026

Browser could not establish a connection to the proxy server

You might see this error as:

  • net::ERR_PROXY_CONNECTION_FAILED
  • ERR_PROXY_CONNECTION_FAILED Chrome
  • Proxy connection failed
  • Unable to connect to proxy server
  • ERR_TUNNEL_CONNECTION_FAILED

What Does This Error Mean?

ERR_PROXY_CONNECTION_FAILED occurs when the browser is configured to use a proxy server but cannot establish a connection to that proxy. The browser is not even attempting to connect to the destination website — it fails at the step of connecting to the intermediary proxy. This is typically caused by incorrect proxy settings, the proxy server being offline, or network issues between the client and the proxy.

Common Causes

  • Proxy server is offline — The configured proxy server is not running, has crashed, or is undergoing maintenance, making it impossible for the browser to establish a connection.
  • Incorrect proxy settings — The proxy address, port, or authentication credentials configured in the browser or operating system are wrong, pointing to a non-existent or incorrect proxy server.
  • Proxy auto-configuration (PAC) script errors — The PAC file that determines which proxy to use contains errors, returns an invalid proxy address, or the PAC file URL itself is unreachable.
  • Malware changed proxy settings — Malware or adware has modified the system proxy settings to route traffic through a malicious proxy that is no longer available or was taken down.
  • Firewall blocking proxy port — A firewall is blocking the connection to the proxy server's port, preventing the browser from reaching the proxy even though the proxy itself may be running.

How to Fix It

1. Check and fix proxy settings

Review your proxy configuration in the browser and operating system settings. If you do not need a proxy, disable it entirely.

# Windows: Check proxy settings
netsh winhttp show proxy

# To reset proxy settings
netsh winhttp reset proxy

2. Disable automatic proxy detection

Turn off 'Automatically detect settings' in your network proxy settings. This feature sometimes detects incorrect proxy configurations from the network.

3. Scan for malware

Run a malware scan to check if malicious software has modified your proxy settings. Some malware redirects traffic through rogue proxies for data interception.

4. Contact your network administrator

In corporate or school environments, proxy settings are often managed centrally. Contact your IT department to verify the correct proxy configuration and ensure the proxy server is operational.

Frequently Asked Questions

How do I know if I should be using a proxy?

Most home users do not need a proxy. If you are on a corporate or school network, your IT department will tell you. If you are unsure, try disabling the proxy — if browsing works without it, you do not need one.

Can a VPN cause this error?

Yes. Some VPN software configures a local proxy as part of its setup. If the VPN disconnects but leaves the proxy settings in place, you will see this error. Reconnect the VPN or remove the proxy settings.

Why does only Chrome show this error while other browsers work?

Different browsers can have different proxy settings. Chrome uses the system proxy settings on Windows and macOS, while Firefox has its own proxy configuration. Check the proxy settings in each browser independently.
