Python Errors

Python errors span environment setup (python not found, externally-managed-environment, broken venvs), imports, encodings, and runtime crashes. These guides carry the exact tracebacks with working fixes. ModuleNotFoundError and general pip install failures live in the DevOps category and are cross-listed below.

Python
AttributeError: 'NoneType' Object Has No Attribute
The most common Python traceback — a variable is None where code expected a real object, usually because some earlier call returned None.
 Python
error: Microsoft Visual C++ 14.0 or Greater Is Required
The pip build failure 'error: Microsoft Visual C++ 14.0 or greater is required. Get it with Microsoft C++ Build Tools' — a package needs compiling and Windows has no compiler.
 DevOps
pip Install Failed
pip package installation failed with error
 Python
pip: TLS/SSL Module Not Available
The failure 'pip is configured with locations that require TLS/SSL, however the ssl module in Python is not available' — this Python was built without OpenSSL support.
 Python
Python error: externally-managed-environment
The pip refusal 'error: externally-managed-environment' — the system Python (Debian 12+, Ubuntu 23.04+, Fedora 38+, Homebrew) blocks pip installs outside a virtual environment.
 Python
Python ImportError: Attempted Relative Import
The crash 'ImportError: attempted relative import with no known parent package' — relative imports only work inside a package, and this file was run as a plain script.
 Python
Python IndentationError
Crashes like 'IndentationError: unexpected indent', 'expected an indented block', and 'unindent does not match any outer indentation level' — whitespace that Python cannot parse as structure.
 DevOps
Python ModuleNotFoundError
Python cannot find the specified module
 Python
Python RecursionError: Maximum Recursion Depth Exceeded
The crash 'RecursionError: maximum recursion depth exceeded' — function calls nested past Python's limit (default 1000), almost always runaway recursion.
 Python
Python SSLCertVerificationError — Certificate Verify Failed
The failure 'ssl.SSLCertVerificationError: [SSL: CERTIFICATE_VERIFY_FAILED] certificate verify failed: unable to get local issuer certificate' in requests, urllib, or pip.
 Python
Python UnicodeDecodeError
The crash "UnicodeDecodeError: 'utf-8' codec can't decode byte 0x.. in position .." — bytes were decoded with the wrong encoding, or binary data was opened as text.
 Python
python: command not found
Shell errors 'python: command not found' or Windows opening the Microsoft Store — the python command is missing from PATH, or only python3 exists.
 Python
Python: No Module Named pip
The failure 'ModuleNotFoundError: No module named pip' (or '/usr/bin/python3: No module named pip') — this interpreter has no pip installed at all.
 Python
venv Activate: Running Scripts Is Disabled on This System
The PowerShell failure 'Activate.ps1 cannot be loaded because running scripts is disabled on this system' — Windows' execution policy blocks the venv activation script.
