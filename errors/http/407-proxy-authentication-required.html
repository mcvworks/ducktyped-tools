407 Proxy Authentication Required

Last updated: March 8, 2026

The client must authenticate with the proxy before the request can proceed

You might see this error as:

  • HTTP 407
  • 407 Proxy Authentication Required
  • 407 error
  • Proxy auth required
  • Proxy-Authenticate header

What Does This Error Mean?

A 407 Proxy Authentication Required response indicates that the client must first authenticate with an intermediary proxy server before the request can be forwarded to the destination. The proxy returns a Proxy-Authenticate header indicating the authentication scheme required. This is similar to 401 Unauthorized, but applies to the proxy rather than the origin server.

Common Causes

  • Missing proxy credentials — The HTTP client is connecting through a proxy that requires authentication, but no credentials were provided in the Proxy-Authorization header.
  • Expired or invalid proxy credentials — The proxy credentials have expired, been changed, or are incorrect. The proxy server rejects the authentication attempt and requests new credentials.
  • Corporate proxy enforcement — A corporate network proxy requires all outbound traffic to be authenticated, and the application or tool making the request is not configured with proxy credentials.
  • Proxy configuration mismatch — The system proxy settings specify a proxy server, but the application is not using the correct authentication scheme (Basic, Digest, NTLM, Kerberos) expected by the proxy.

How to Fix It

1. Configure proxy credentials

Set the proxy authentication credentials in your HTTP client or system proxy settings. Most tools accept proxy credentials in the proxy URL format.

# curl with proxy authentication
curl -x http://user:password@proxy.example.com:8080 https://example.com

# Environment variable
export https_proxy=http://user:password@proxy.example.com:8080

2. Check proxy authentication scheme

Inspect the Proxy-Authenticate header in the 407 response to determine which authentication scheme the proxy requires (Basic, Digest, NTLM, Negotiate) and configure your client accordingly.

3. Update stored proxy credentials

If your proxy password has changed, update the stored credentials in your operating system's proxy settings, browser configuration, or application environment variables.

Frequently Asked Questions

What is the difference between 401 and 407?

A 401 means the origin server requires authentication. A 407 means an intermediary proxy server requires authentication. They use different headers: WWW-Authenticate (401) vs Proxy-Authenticate (407).

How do I find out which proxy is blocking my requests?

Check your system proxy settings (network preferences on macOS, Internet Options on Windows, or environment variables on Linux). The proxy URL will indicate the server requiring authentication.

Can browser extensions cause 407 errors?

Extensions that route traffic through proxy servers can trigger 407 if they require authentication. Check your installed extensions, especially VPN or privacy-related ones.
