431 Request Header Fields Too Large

Last updated: March 8, 2026

The request headers are too large for the server to process

You might see this error as:

  • HTTP 431
  • 431 Request Header Fields Too Large
  • 431 error
  • Headers too large
  • Cookie too large
  • Request header too long

What Does This Error Mean?

A 431 Request Header Fields Too Large response indicates that the server refuses to process the request because one or more header fields, or the total size of all headers, exceeds the server's configured maximum. This commonly occurs when cookies accumulate to excessive sizes, authorization tokens are very large, or custom headers contain too much data.

Common Causes

  • Excessive cookie size — The browser has accumulated many cookies for the domain, and the total Cookie header size exceeds the server's header size limit. This is the most common cause.
  • Large authorization token — A JWT or other authorization token in the Authorization header is unusually large, often due to embedding too many claims or permissions.
  • Too many custom headers — The request includes many custom headers (e.g., from browser extensions, proxy chains, or middleware) that together exceed the header size limit.
  • Server header buffer too small — The server's configured header buffer size is too small for the application's normal request patterns.

How to Fix It

1. Clear cookies for the domain

Clear cookies for the affected domain in your browser. This is the most common fix since large Cookie headers are the primary cause of 431 errors.

2. Increase server header buffer size

If you control the server, increase the maximum allowed header size.

# Nginx
large_client_header_buffers 4 32k;

# Apache
LimitRequestFieldSize 16384

# Node.js
http.createServer({ maxHeaderSize: 32768 }, handler);

3. Reduce JWT token size

If large JWTs are the issue, reduce the number of claims embedded in the token. Move detailed permissions to a server-side lookup instead of encoding them in the token.

4. Audit and remove unnecessary cookies

Review which cookies are being set for the domain and remove unnecessary ones. Set appropriate domain and path scopes to avoid sending irrelevant cookies.

Frequently Asked Questions

What is the maximum header size?

There is no official limit in the HTTP specification. Nginx defaults to 8KB per header line and 8KB total. Apache defaults to 8,190 bytes per field. Node.js defaults to 16KB total.

Why does clearing cookies fix 431 errors?

Cookies are sent as headers with every request to a domain. Over time, third-party scripts and subdomains can accumulate many cookies, causing the total Cookie header to exceed server limits.

Can this error happen on only some pages?

Yes. Different pages may set different cookies or trigger different headers. A page that sets additional cookies might push the total header size over the limit.
