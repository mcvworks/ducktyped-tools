501 Not Implemented

Last updated: March 8, 2026

A 501 error means the server does not support the HTTP method in the request. The server lacks the functionality to fulfill the request.

You might see this error as:

  • HTTP 501
  • 501 Not Implemented
  • 501 error
  • Method not implemented
  • 501 server error

What Does This Error Mean?

HTTP 501 is returned when the server does not recognize or implement the HTTP method used in the request. All HTTP servers are required to support GET and HEAD. Other methods like PATCH, PUT, DELETE, and CONNECT are optional — a server may return 501 for any method it does not support.

This is a server-side limitation, not a client error. The 501 response may include an Allow header listing the methods the server does support.

Common Causes

  • Unsupported HTTP method — sending PATCH, PUT, or DELETE to a server that only handles GET and POST.
  • Proxy server limitation — a proxy in the chain does not support the requested method and returns 501 instead of forwarding it.
  • Incomplete API implementation — a developer planned an endpoint but has not yet implemented the method handler.
  • Web framework routing gap — no route handler registered for that HTTP method on the endpoint.

How to Fix It

For API Consumers

1. Check the API Documentation

Verify which HTTP methods the endpoint supports. You may be using PATCH when the API only supports PUT, or vice versa.

2. Check the Allow Header

The 501 response may include an Allow header listing supported methods: Allow: GET, POST, PUT. Use one of those methods instead.

For Server Owners

3. Implement the Required Method Handler

Add a route handler for the method in your web framework:

# Express.js example
app.patch('/resource/:id', (req, res) => {
    // implement handler
});

4. Return 405 Instead of 501 Where Appropriate

If the server supports the method globally but a specific route does not, return 405 Method Not Allowed with an Allow header. Reserve 501 for methods the server does not implement at all.

Frequently Asked Questions

Does 501 mean the feature is coming soon?

Not officially — 501 just means "not supported." However, some developers use it as a placeholder for endpoints they plan to implement. Check the API changelog or contact the provider for clarification.

Can I encounter 501 on a normal website?

Rarely. Browsers typically only send GET requests for page loads. 501 is more commonly encountered when making API requests programmatically with PATCH, PUT, DELETE, or custom methods.

Related Errors
