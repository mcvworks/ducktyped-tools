415 Unsupported Media Type

Last updated: March 8, 2026

A 415 error means the server refuses to accept the request because the Content-Type header indicates a format the endpoint does not support.

You might see this error as:

  • HTTP 415
  • 415 Unsupported Media Type
  • 415 error
  • Content-Type not supported
  • Wrong Content-Type header

What Does This Error Mean?

HTTP 415 indicates a content negotiation failure on the request body. The server checks your request's Content-Type header before processing the body, and if the format is not in its list of accepted types, it rejects the request without even reading the body.

This is the server saying: "I don't know how to handle this format." It is the request-body counterpart of 406 Not Acceptable, which applies to the response format.

Common Causes

  • Missing Content-Type header — sending a body without declaring its format.
  • Wrong Content-Type — sending JSON but declaring text/plain, or sending form data with application/json.
  • XML to a JSON-only API — the API accepts only JSON but the request uses XML.
  • Form data format mismatch — using multipart/form-data when the endpoint requires application/x-www-form-urlencoded.
  • Unsupported file type in upload — uploading an MP4 to an endpoint that only accepts images.

How to Fix It

1. Set the Correct Content-Type Header

For JSON APIs:

Content-Type: application/json

For HTML form submissions:

Content-Type: application/x-www-form-urlencoded

For file uploads:

Content-Type: multipart/form-data

2. Check the API Documentation

Review the endpoint's documentation to confirm which media types it accepts. Look for an Accept or Consumes specification.

3. Verify Your Request Body Matches the Content-Type

If you declare application/json, ensure the body is valid JSON. If you declare application/x-www-form-urlencoded, ensure the body is URL-encoded key-value pairs.

Frequently Asked Questions

Does 415 affect GET requests?

Rarely. GET requests typically have no body, so Content-Type is irrelevant. 415 almost exclusively affects POST, PUT, and PATCH requests that include a body.

Can a proxy cause 415?

Yes. Some proxies modify or strip Content-Type headers in ways that cause the endpoint to reject the request. If the 415 error is inconsistent, inspect the request headers at the server using access logs.
