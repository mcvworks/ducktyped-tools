410 Gone

Last updated: March 8, 2026

A 410 status means the resource has been permanently removed and will not return. It is a definitive signal to users, browsers, and search engines that this URL no longer exists.

You might see this error as:

  • HTTP 410
  • 410 Gone
  • 410 error
  • Resource permanently removed
  • 410 vs 404
  • 410 SEO

What Does This Error Mean?

HTTP 410 is a permanent version of 404 Not Found. While 404 says "I can't find this," 410 says "this used to exist here and I intentionally removed it — do not look for it again."

The 410 response has no body requirements beyond optionally explaining the removal. It should be used only when you are certain the resource will never return. If there is a replacement URL, prefer a 301 redirect instead.

Common Use Cases

  • Permanently deleted content — a blog post, product, or page that has been intentionally removed.
  • Retired API endpoints — an API version that has been decommissioned.
  • Deactivated user accounts — a public profile that belonged to a deleted account.
  • Expired promotional pages — a campaign landing page no longer active.
  • Removed features — a product feature that has been discontinued.

410 vs. 404 — Choosing the Right Code

SituationCode
Resource might return in the future404
Resource permanently deleted410
Resource moved to new URL301 redirect
Temporary removal503 or 404

SEO Impact

Search engines like Google treat 410 more aggressively than 404. Pages returning 410 are de-indexed faster from search results than pages returning 404. If you want to quickly remove a URL from search results, returning 410 is more efficient than 404.

However, Google has stated that they eventually treat both 404 and 410 the same — both result in de-indexing. The difference is primarily in speed.

How to Implement 410

In nginx

location /old-page {
    return 410;
}

In Apache (.htaccess)

RedirectMatch 410 ^/old-page$

In Node.js/Express

app.get('/old-page', (req, res) => {
    res.status(410).send('This resource has been permanently removed.');
});

Frequently Asked Questions

Should I redirect 410 pages to my homepage?

Only if the homepage is a relevant replacement. Redirecting all removed pages to a homepage passes little value and can create a "soft 404" that confuses search engines. If there is no replacement URL, return 410 or 404 with an informative message.

Can I change a 410 back to 200 later?

Technically yes, but it contradicts the semantics of 410. If you think the resource might return, use 404 instead. 410 is meant to be a permanent signal.

Related Errors

  • 301 Moved Permanently — resource moved to a new URL permanently.
