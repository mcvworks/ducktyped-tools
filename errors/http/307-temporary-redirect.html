307 Temporary Redirect

Last updated: March 8, 2026

The resource temporarily resides at a different URL, preserving the request method

You might see this error as:

  • HTTP 307
  • 307 Temporary Redirect
  • 307 status code
  • HSTS redirect 307
  • 307 vs 302

What Does This Error Mean?

A 307 Temporary Redirect tells the client that the resource temporarily resides at a different URI and the client must not change the request method when following the redirect. Unlike 302, which historically allowed clients to change POST to GET, 307 guarantees that the method and body are preserved. This is important for form submissions and API requests.

Common Causes

  • HSTS redirect from HTTP to HTTPS — Browsers that have an HSTS policy cached for a domain will internally redirect HTTP requests to HTTPS using a 307 before the request even reaches the network.
  • Temporary API endpoint migration — An API endpoint has been temporarily moved, and the server uses 307 to ensure POST, PUT, and DELETE requests are forwarded with their original method and body.
  • Load balancer routing — A load balancer or reverse proxy is temporarily routing requests to a different backend server while preserving the original request method.

How to Fix It

1. Follow the redirect with the same method

HTTP clients should automatically follow 307 redirects using the same method. If your client is not following the redirect, check that it supports 307 and is configured to follow redirects.

2. Use 308 for permanent method-preserving redirects

If the redirect is permanent, use 308 instead of 307. The 308 status code has the same method-preserving semantics but indicates the move is permanent.

3. Update API client endpoints

If you are consuming an API that returns 307, update your client configuration to point to the new URL directly to avoid the redirect overhead.

# Check where a URL redirects to
curl -I -L https://api.example.com/old-endpoint

Frequently Asked Questions

What is the difference between 302 and 307?

Both are temporary redirects, but 307 guarantees that the request method is not changed. With 302, some clients may change POST to GET. Use 307 when method preservation is important.

Why do I see 307 redirects in DevTools when visiting HTTP URLs?

If the site uses HSTS (HTTP Strict Transport Security), your browser internally generates a 307 redirect from HTTP to HTTPS. This happens before any network request is sent.
