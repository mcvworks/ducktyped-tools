HTTP Errors

Last updated: March 8, 2026

HTTP status error codes are returned by web servers to indicate what went wrong with a request. 4xx codes signal client-side problems like missing pages or missing authentication. 5xx codes indicate server-side failures. Use the guides below to understand each error and how to resolve it.

3xx Redirection
HTTP
301 Moved Permanently
The requested resource has been permanently moved to a new URL.
 HTTP
302 Found
The requested resource temporarily resides at a different URL.
 HTTP
304 Not Modified
The resource has not been modified since the last request.
 HTTP
307 Temporary Redirect
The resource temporarily resides at a different URL, preserving the request method.
 HTTP
308 Permanent Redirect
The resource has permanently moved, preserving the request method.
4xx Client Errors
HTTP
400 Bad Request
The server could not process the request due to malformed syntax or invalid parameters.
 HTTP
401 Unauthorized
Authentication is required and the request did not provide valid credentials.
 HTTP
403 Forbidden
The server refuses to authorize access to the requested resource.
 HTTP
404 Not Found
The requested page or resource does not exist on the server.
 HTTP
405 Method Not Allowed
The HTTP method used is not allowed for the requested resource.
 HTTP
406 Not Acceptable
The server cannot produce a response matching the client's Accept headers.
 HTTP
407 Proxy Authentication Required
The client must authenticate with the proxy before the request can proceed.
 HTTP
408 Request Timeout
The server closed the connection because the client took too long to send the request.
 HTTP
409 Conflict
The request conflicts with the current state of the resource on the server.
 HTTP
410 Gone
The requested resource has been permanently removed from the server.
 HTTP
411 Length Required
The server requires a Content-Length header in the request.
 HTTP
412 Precondition Failed
One or more precondition headers evaluated to false on the server.
 HTTP
413 Payload Too Large
The request body exceeds the server's size limit.
 HTTP
414 URI Too Long
The request URL is longer than the server is willing to process.
 HTTP
415 Unsupported Media Type
The server refuses to accept the request because the Content-Type is not supported.
 HTTP
416 Range Not Satisfiable
The requested byte range cannot be fulfilled by the server.
 HTTP
417 Expectation Failed
The server cannot meet the requirements of the Expect header.
 HTTP
418 I'm a Teapot
The server refuses to brew coffee because it is a teapot.
 HTTP
421 Misdirected Request
The request was directed to a server that cannot produce a response.
 HTTP
422 Unprocessable Entity
The request syntax is valid but the content fails semantic validation.
 HTTP
429 Too Many Requests
The client has sent too many requests in a short period and hit the server's rate limit.
 HTTP
423 Locked
The resource is locked and cannot be modified.
 HTTP
424 Failed Dependency
The request failed because it depended on another request that also failed.
 HTTP
425 Too Early
The server is unwilling to process a request that might be replayed.
 HTTP
426 Upgrade Required
The server requires the client to upgrade to a different protocol.
 HTTP
428 Precondition Required
The server requires the request to be conditional.
 HTTP
431 Request Header Fields Too Large
The request headers are too large for the server to process.
 HTTP
451 Unavailable For Legal Reasons
The resource is unavailable due to legal demands.
5xx Server Errors
HTTP
500 Internal Server Error
The server encountered an unexpected error while processing the request.
 HTTP
501 Not Implemented
The server does not support the HTTP method used in the request.
 HTTP
502 Bad Gateway
A proxy or gateway received an invalid response from the upstream server.
 HTTP
503 Service Unavailable
The server is temporarily unable to handle requests — usually due to maintenance or overload.
 HTTP
504 Gateway Timeout
The gateway timed out waiting for an upstream server to respond.
 HTTP
507 Insufficient Storage
The server cannot store the data needed to complete the request.
 HTTP
506 Variant Also Negotiates
The server has a circular reference in content negotiation.
 HTTP
508 Loop Detected
The server detected an infinite loop while processing the request.
 HTTP
510 Not Extended
The request requires an HTTP extension that the server does not support.
 HTTP
511 Network Authentication Required
The client needs to authenticate to gain network access.
