301 Moved Permanently

Last updated: March 8, 2026

The requested resource has been permanently moved to a new URL

You might see this error as:

  • HTTP 301
  • 301 redirect
  • 301 Moved Permanently
  • Permanent redirect
  • 301 status code
  • 301 SEO redirect

What Does This Error Mean?

A 301 Moved Permanently response indicates that the requested resource has been assigned a new permanent URI and future requests should use the new URL. Search engines transfer ranking signals from the old URL to the new one. This is the standard way to permanently redirect traffic from one URL to another.

Common Causes

  • Domain or URL migration — The website has moved to a new domain or the URL structure has been reorganized, and the server is redirecting visitors to the new location.
  • HTTP to HTTPS enforcement — The server is configured to redirect all HTTP requests to HTTPS, issuing a 301 to ensure browsers always use the secure version.
  • Trailing slash normalization — The server enforces a canonical URL format by redirecting requests with or without a trailing slash to the preferred version.
  • www/non-www canonicalization — The server redirects between www and non-www versions of the domain to consolidate traffic under a single canonical hostname.

How to Fix It

1. Follow the redirect to the new URL

Update bookmarks, links, and API endpoints to point directly to the new URL provided in the Location header. Browsers handle this automatically, but hardcoded URLs in applications should be updated.

2. Configure the redirect in your web server

If you are setting up a 301 redirect, configure it in your server. In Nginx, use a return directive. In Apache, use Redirect or RewriteRule.

# Nginx
server {
    listen 80;
    server_name old-domain.com;
    return 301 https://new-domain.com$request_uri;
}

3. Check for redirect chains

Ensure you are not chaining multiple 301 redirects (A -> B -> C). Each hop adds latency and search engines may not follow long chains. Use a redirect checker tool to trace the full chain.

Frequently Asked Questions

Does a 301 redirect pass SEO value?

Yes. A 301 redirect transfers the majority of link equity and ranking signals from the old URL to the new one. It is the recommended redirect type for permanent URL changes.

What is the difference between 301 and 302 redirects?

A 301 indicates a permanent move and tells search engines to index the new URL. A 302 indicates a temporary redirect and tells search engines to keep indexing the original URL.

Can a 301 redirect be reversed?

Yes, but browsers cache 301 redirects aggressively. After removing a 301, users may still be redirected until their browser cache expires. You may need to clear browser cache or wait for the cache TTL.
