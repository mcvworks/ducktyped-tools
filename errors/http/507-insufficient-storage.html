507 Insufficient Storage

Last updated: March 8, 2026

A 507 error means the server cannot store the data needed to complete the request. The server's disk is full or the user's quota is exceeded.

You might see this error as:

  • HTTP 507
  • 507 Insufficient Storage
  • 507 error
  • Insufficient storage
  • WebDAV storage full

What Does This Error Mean?

HTTP 507 is defined in RFC 4918 (WebDAV extensions) but is used more broadly to indicate that the server cannot complete the request due to insufficient storage space. The response may be temporary — once space is freed, the same request can succeed.

This differs from 500 Internal Server Error — 507 specifically identifies storage as the cause, making it actionable.

Common Causes

  • Server disk full — the server's storage partition has no remaining space.
  • User storage quota exceeded — a per-user limit has been reached (file upload services, cloud storage).
  • Large file upload — a file being uploaded exceeds available space.
  • WebDAV collection full — a WebDAV resource collection is at its storage limit.
  • Log files or temp files consuming space — server side processes have consumed all available disk.
  • Database storage limit — the database volume is full, preventing new records from being written.

How to Fix It

For Users

1. Check Your Storage Quota

If using a file upload service, cloud storage, or similar application, check your account's storage usage. Delete old or unnecessary files to free space, or upgrade to a tier with more storage.

For Server Owners

2. Free Up Disk Space

df -h                        # check disk usage
du -sh /var/log/*            # large log files?
du -sh /tmp/*                # temporary files?
journalctl --disk-usage      # systemd journal size

3. Implement Log Rotation

Configure logrotate to automatically compress and rotate log files. This prevents log directories from growing unbounded.

4. Expand Storage

Add a new disk volume or expand the existing partition. For cloud servers, this is typically a few clicks in the cloud provider's console.

5. Implement Storage Quotas

Set per-user or per-directory quotas to prevent any single user or process from consuming all available storage.

Frequently Asked Questions

Is 507 the same as a full hard drive?

Yes, essentially. 507 is the HTTP status code for "the server's storage is full." The underlying cause is a disk full condition on the server (or a quota being hit), which the server communicates to the client via this response code.

Should I retry after a 507?

Yes, once the storage condition is resolved. Unlike a 5xx permanent error, storage issues are recoverable. The RFC suggests including a Retry-After header with 507 to indicate when space may become available.

Related Errors

  • 500 Internal Server Error — generic server failure.
  • 503 Service Unavailable — server temporarily unable to handle requests.
  • SMTP 452 — mail server insufficient storage.
