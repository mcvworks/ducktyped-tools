Node.js Errors

Node.js errors range from module resolution (Cannot find module, ERR_REQUIRE_ESM) to runtime crashes (heap out of memory, unhandled rejections) and toolchain failures (node-gyp, OpenSSL). These guides cover the exact error text with working fixes. npm network and permission errors (ERESOLVE, EACCES...) live in the DevOps category and are cross-listed below.

Node.js
Cannot Use Import Statement Outside a Module
The crash "SyntaxError: Cannot use import statement outside a module" — ES-module syntax ran in a CommonJS context, in Node, Jest, or a browser script tag.
 DNS
getaddrinfo EAI_AGAIN
A temporary DNS resolution failure in Node.js and other applications — the resolver could not get an answer in time, often inside Docker containers or CI environments.
 DNS
getaddrinfo ENOTFOUND
A Node.js error thrown when a hostname cannot be resolved to an IP address — the DNS lookup returned no result for the name your code tried to connect to.
 Node.js
JavaScript Heap Out of Memory
The crash 'FATAL ERROR: Reached heap limit Allocation failed - JavaScript heap out of memory' — the Node process hit V8's heap ceiling and aborted.
 Node.js
Maximum Call Stack Size Exceeded
The crash 'RangeError: Maximum call stack size exceeded' — function calls nested deeper than the stack allows, almost always runaway recursion.
 Node.js
node-gyp Build Failed
Install failures full of 'gyp ERR! build error' and 'gyp ERR! stack' — a package with native C/C++ code could not compile on your machine.
 Node.js
Node.js Cannot Find Module
The crash "Error: Cannot find module 'x'" (code MODULE_NOT_FOUND) — Node's resolver could not locate a package or file your code requires or imports.
 Node.js
Node.js EADDRINUSE — Address Already in Use
The crash 'Error: listen EADDRINUSE: address already in use :::3000' — another process (often a previous instance of the same app) already listens on the port.
 Node.js
Node.js ERR_REQUIRE_ESM
The crash 'Error [ERR_REQUIRE_ESM]: require() of ES Module ... not supported' — CommonJS code tried to require() a package that ships only as an ES module.
 Node.js
Node.js error:0308010C — Digital Envelope Routines Unsupported
The build crash 'Error: error:0308010C:digital envelope routines::unsupported' — Node 17+ (OpenSSL 3) rejects legacy hash usage in older webpack toolchains.
 Node.js
Node.js UNABLE_TO_GET_ISSUER_CERT_LOCALLY
TLS failures like 'npm ERR! UNABLE_TO_GET_ISSUER_CERT_LOCALLY' or fetch failing with 'unable to get local issuer certificate' — Node cannot verify the server's certificate chain, typically behind a corporate proxy.
 Node.js
Node.js Unhandled Promise Rejection
The crash 'Error [ERR_UNHANDLED_REJECTION]: This error originated either by throwing inside of an async function without a catch block...' — a rejected promise had no handler, and Node 15+ exits.
 DevOps
npm ERR! code EACCES
npm permission denied error
 DevOps
npm ERR! code ECONNRESET
npm connection to registry was reset
 Node.js
npm ERR! code ELIFECYCLE
The npm failure 'npm ERR! code ELIFECYCLE, npm ERR! errno 1' — the package.json script npm ran exited with a non-zero code. npm is the messenger, not the culprit.
 DevOps
npm ERR! code ENOTFOUND
npm cannot reach the registry
 DevOps
npm ERR! code EPERM
npm permission error on file operation
 DevOps
npm ERR! code ERESOLVE
npm dependency resolution conflict
 Node.js
npm ERR! ENOENT — Could Not Read package.json
The failure 'npm ERR! code ENOENT ... Could not read package.json' — npm ran in a directory that has no package.json to read.
 DevOps
Yarn Integrity Check Failed
Yarn detected a mismatch between node_modules and yarn.lock
