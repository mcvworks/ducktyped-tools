Database Connection Timeout

Last updated: March 8, 2026

Database connection attempt timed out

You might see this error as:

  • Database connection timeout
  • Connection timed out to database
  • ETIMEDOUT database
  • db connection timeout
  • Unable to connect to database server

What Does This Error Mean?

A connection timeout occurs when a client attempts to connect to a database server but receives no response within the configured timeout period. Unlike connection refused (which fails immediately), a timeout means the connection request was sent but no response came back, suggesting a network-level issue rather than the server actively rejecting the connection.

Common Causes

  • Firewall blocking the connection silently — A firewall is dropping the connection packets instead of rejecting them. This causes the client to wait until the timeout expires rather than receiving an immediate rejection.
  • Incorrect server hostname or IP — The client is trying to connect to a wrong IP address or hostname that does not route to the database server.
  • Database server is overloaded — The database server is under heavy load and cannot process new connection requests within the timeout period.
  • Network routing issues — Network misconfiguration, VPN disconnection, or security group rules are preventing packets from reaching the database server.
  • Cloud security group misconfiguration — In cloud environments (AWS, GCP, Azure), security groups or network access control lists may not include rules allowing inbound connections on the database port.

How to Fix It

1. Test network connectivity

Verify that the database port is reachable from your client machine.

# Test TCP connection:
nc -zv db-server.example.com 5432
# Or:
telnet db-server.example.com 5432

# Check routing:
traceroute db-server.example.com

2. Verify security group rules

In cloud environments, check that inbound rules allow traffic on the database port from your IP or subnet.

# AWS CLI example:
aws ec2 describe-security-groups --group-ids sg-xxxxx

3. Increase connection timeout

If the server is slow but reachable, increase the client's connection timeout to give it more time.

# PostgreSQL connection string:
postgresql://user:pass@host:5432/db?connect_timeout=30

# MySQL connection:
mysql -h host -u user -p --connect-timeout=30

Frequently Asked Questions

What is the difference between connection timeout and query timeout?

Connection timeout is how long the client waits to establish the initial TCP connection. Query timeout (or statement timeout) is how long the client waits for a query to return results after the connection is established. They are separate settings.

Why does the connection time out from my application but work from the database server?

Connecting from the server itself (localhost) bypasses network infrastructure. The timeout is caused by something in the network path between your application and the database: firewalls, security groups, routing, or VPN configuration.
