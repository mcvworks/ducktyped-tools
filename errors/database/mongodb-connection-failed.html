MongoDB Connection Failed

Last updated: March 8, 2026

MongoDB client could not connect to the server

You might see this error as:

  • MongoDB connection failed
  • MongoNetworkError
  • MongoServerSelectionError
  • connect ECONNREFUSED 27017
  • MongoDB connection refused

What Does This Error Mean?

This error occurs when the MongoDB client or driver cannot establish a connection to the MongoDB server. MongoDB connections can fail due to the server not running, authentication issues, network problems, or incorrect connection string format. MongoDB Atlas (cloud) connections have additional requirements like IP whitelisting.

Common Causes

  • MongoDB server is not running — The mongod or mongos process has stopped. This can happen due to unclean shutdown, configuration errors, or insufficient disk space.
  • Authentication failure — The username, password, or authentication database in the connection string is incorrect. MongoDB uses SCRAM authentication by default.
  • IP not whitelisted (MongoDB Atlas) — When using MongoDB Atlas, the connecting client's IP address must be added to the Atlas IP Access List. Connections from non-whitelisted IPs are rejected.
  • Incorrect connection string format — The MongoDB connection string has syntax errors, missing parameters, or incorrect formatting. The mongodb+srv:// and mongodb:// protocols have different requirements.

How to Fix It

1. Start MongoDB service

Start the MongoDB server and check its status.

sudo systemctl start mongod
sudo systemctl status mongod

# Check MongoDB logs:
sudo tail -n 50 /var/log/mongodb/mongod.log

2. Verify connection string

Test the connection string using the MongoDB shell.

# Local connection:
mongosh "mongodb://localhost:27017/mydb"

# Authenticated connection:
mongosh "mongodb://user:password@localhost:27017/mydb?authSource=admin"

# Atlas connection:
mongosh "mongodb+srv://user:password@cluster.mongodb.net/mydb"

3. Whitelist IP in MongoDB Atlas

In the Atlas web console, go to Network Access and add your current IP address or use 0.0.0.0/0 for development (not recommended for production).

Frequently Asked Questions

What is the difference between mongodb:// and mongodb+srv://?

mongodb:// is the standard connection string that requires explicit host:port pairs. mongodb+srv:// uses DNS SRV records to discover the cluster members, which is required for MongoDB Atlas and simplifies connection strings for replica sets.

What is the authSource parameter?

authSource specifies the database that contains the user's credentials. It defaults to the database in the connection string, but users are often created in the 'admin' database, requiring authSource=admin.
