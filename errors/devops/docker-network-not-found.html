Docker Network Not Found

Last updated: March 8, 2026

Docker network does not exist

You might see this error as:

  • Docker network not found
  • network not found
  • Error: No such network
  • docker network error

What Does This Error Mean?

This error occurs when a container or Docker Compose service references a network that does not exist. Docker networks provide isolated communication channels between containers. If the network was removed or never created, containers cannot attach to it.

Common Causes

  • Network was manually removed — Someone ran 'docker network rm' or 'docker system prune' which removed the network that containers depend on.
  • Docker Compose project was not started — Docker Compose creates networks automatically when starting services. If the Compose project has not been started, its networks do not exist yet.
  • Typo in network name — The network name in the docker run command or Compose file does not match any existing network due to a spelling mistake.

How to Fix It

1. Create the missing network

Manually create the network that your container expects to use.

docker network create my-network
docker network ls

2. Start the Docker Compose project

If the network is defined in a Compose file, run docker-compose up to create all defined networks and services.

docker-compose up -d

3. Check network name spelling

List existing networks and verify the name matches what your container configuration expects.

docker network ls
docker network inspect my-network

Frequently Asked Questions

Does docker system prune remove networks?

Yes. 'docker system prune' removes all unused networks, along with stopped containers and dangling images. Networks currently in use by running containers are preserved.

Can I connect a running container to a new network?

Yes. Use 'docker network connect <network> <container>' to attach a running container to an additional network without restarting it.
