npm ERR! code ENOTFOUND

Last updated: March 8, 2026

npm cannot reach the registry

You might see this error as:

  • npm ERR! ENOTFOUND
  • getaddrinfo ENOTFOUND registry.npmjs.org
  • npm ERR! network
  • npm DNS error
  • npm cannot reach registry

What Does This Error Mean?

ENOTFOUND means npm cannot resolve the hostname of the package registry (typically registry.npmjs.org) via DNS. This prevents npm from downloading packages. The issue is usually related to network connectivity, DNS configuration, or proxy settings rather than a problem with npm itself.

Common Causes

  • No internet connection — The machine has no active internet connection or the connection is unstable, preventing DNS resolution and registry access.
  • DNS resolution failure — The DNS server cannot resolve registry.npmjs.org. This can happen with misconfigured DNS settings, DNS server outages, or network restrictions.
  • Corporate proxy not configured — The machine is behind a corporate proxy that requires specific configuration in npm. Without proxy settings, npm cannot reach the external registry.
  • Incorrect registry URL configured — The npm registry URL has been changed in .npmrc to an incorrect or unreachable URL.

How to Fix It

1. Check internet connectivity

Verify that you can reach the npm registry from your machine.

ping registry.npmjs.org
curl -I https://registry.npmjs.org/

2. Reset registry to default

Ensure npm is configured to use the official registry.

npm config set registry https://registry.npmjs.org/
npm config get registry

3. Configure proxy settings

If behind a corporate proxy, configure npm to use it.

npm config set proxy http://proxy.company.com:8080
npm config set https-proxy http://proxy.company.com:8080

Frequently Asked Questions

How do I check my current npm registry?

Run 'npm config get registry'. The default is https://registry.npmjs.org/. If it shows a different URL, that may be the source of the problem.

Can I install packages offline?

Yes. You can use 'npm cache' for previously downloaded packages, or tools like Verdaccio to run a local npm registry. You can also use 'npm pack' to create tarballs for offline installation.
