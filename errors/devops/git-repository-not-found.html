fatal: repository not found

Last updated: March 8, 2026

Git cannot find the remote repository

You might see this error as:

  • Git repository not found
  • fatal: repository not found
  • remote: Repository not found
  • ERROR: Repository not found
  • The requested URL returned error: 403

What Does This Error Mean?

This error occurs when Git cannot access the remote repository specified in the command. The repository URL may be incorrect, the repository may have been deleted or renamed, or the user may lack permission to access it. This is one of the most common Git errors when cloning or pushing.

Common Causes

  • Incorrect repository URL — The URL specified in the git clone or remote configuration is wrong. This includes typos in the username, repository name, or hostname.
  • Repository was deleted or renamed — The repository existed previously but has since been deleted, made private, or renamed on the hosting platform.
  • Authentication credentials are invalid — Your stored credentials (personal access token, SSH key, or password) have expired or been revoked. GitHub returns 'repository not found' instead of 'access denied' for private repos when credentials fail.
  • Insufficient permissions — Your account does not have access to the repository. For GitHub, you need at least read access. The platform intentionally shows 'not found' instead of 'forbidden' for security reasons.

How to Fix It

1. Verify the repository URL

Check that the repository URL is correct by visiting it in a browser. Ensure the username and repository name are spelled correctly.

git remote -v
# Update if wrong:
git remote set-url origin https://github.com/user/repo.git

2. Re-authenticate with the remote

If the repo is private, ensure your credentials are valid. For GitHub, use a personal access token instead of a password.

# Clear cached credentials:
git credential reject <<EOF
host=github.com
protocol=https
EOF

# Then retry - you'll be prompted for new credentials

3. Check repository visibility and access

Visit the repository URL in a browser while logged in. If it returns a 404 page, you either have the wrong URL or lack access. Ask the repository owner to grant you access.

Frequently Asked Questions

Why does GitHub show 'not found' instead of 'access denied'?

This is intentional. Revealing that a private repository exists (but you cannot access it) is an information leak. By returning 'not found' for both missing and inaccessible repos, GitHub protects the privacy of repository owners.

Do I need a personal access token for GitHub?

Yes. GitHub stopped accepting account passwords for Git operations in August 2021. You need a personal access token (classic or fine-grained) or SSH key for authentication.

How do I check if my SSH key is configured correctly?

Run 'ssh -T git@github.com' (or the appropriate host). If configured correctly, you will see a message confirming your username. If it fails, check that your key is added to ssh-agent and your GitHub account.
