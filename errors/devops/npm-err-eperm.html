npm ERR! code EPERM

Last updated: March 8, 2026

npm permission error on file operation

You might see this error as:

  • npm ERR! EPERM
  • EPERM: operation not permitted
  • npm EPERM error Windows
  • Error: EPERM operation not permitted
  • npm cache clean EPERM

What Does This Error Mean?

EPERM (operation not permitted) occurs when npm tries to perform a file operation but is denied by the operating system. This is different from EACCES and is more common on Windows, where file locking by other processes (antivirus, editors, other npm instances) prevents npm from reading, writing, or deleting files in node_modules.

Common Causes

  • File locked by another process — On Windows, antivirus software, file indexing services, or another npm instance may have locked files in node_modules, preventing npm from modifying them.
  • Another npm process is running — A previous npm install that crashed or is still running in another terminal is holding locks on package files.
  • Insufficient file system permissions — The user account does not have write permissions to the project directory or the global npm prefix directory.

How to Fix It

1. Close other applications and retry

Close your editor, stop any running development servers, and temporarily disable antivirus real-time scanning, then retry.

# Delete node_modules and retry:
rm -rf node_modules package-lock.json
npm install

2. Clear npm cache

Force clear the npm cache which may contain corrupted or locked files.

npm cache clean --force
npm install

3. Run as administrator (Windows)

On Windows, open a terminal as Administrator. However, this is a temporary fix. The proper solution is to fix the underlying permission issue.

# In PowerShell as Admin:
npm install

Frequently Asked Questions

What is the difference between EPERM and EACCES?

EPERM means the operation is not permitted regardless of permissions (often due to file locking or OS-level restrictions). EACCES means access denied due to file ownership or permission bits. EPERM is more common on Windows; EACCES is more common on Unix systems.

Why does antivirus cause EPERM errors?

Antivirus software scans files as they are created or modified. During npm install, thousands of files are being written rapidly. The antivirus may lock files for scanning at the exact moment npm tries to modify them, causing EPERM.
