Python ModuleNotFoundError

Last updated: March 8, 2026

Python cannot find the specified module

You might see this error as:

  • ModuleNotFoundError
  • No module named
  • ModuleNotFoundError: No module named Python
  • ImportError: No module named
  • pip install module not found

What Does This Error Mean?

ModuleNotFoundError occurs when Python's import system cannot locate the module you are trying to import. This can mean the module is not installed, is installed in a different Python environment, or the module name is misspelled. In Python 2, this appears as ImportError.

Common Causes

  • Module is not installed — The package has not been installed via pip or another package manager. The module needs to be explicitly installed before it can be imported.
  • Wrong Python environment or virtual environment — The module is installed in a different Python installation or virtual environment than the one currently active. This is very common when switching between projects.
  • Module name differs from package name — The pip package name is different from the import name. For example, 'pip install Pillow' but 'import PIL', or 'pip install python-dotenv' but 'import dotenv'.
  • Python path does not include the module location — The module exists on disk but is not in any of the directories listed in sys.path, so Python's import system cannot find it.

How to Fix It

1. Install the missing module

Use pip to install the module. Make sure you are using the correct pip for your Python version.

pip install module-name
# Or for Python 3 specifically:
python3 -m pip install module-name

2. Activate the correct virtual environment

Ensure your virtual environment is activated before running your script.

# Create and activate venv:
python3 -m venv venv
source venv/bin/activate  # Linux/macOS
venv\Scripts\activate     # Windows
pip install -r requirements.txt

3. Verify installation and check Python path

Confirm the module is installed and check where Python is looking for modules.

pip list | grep module-name
python3 -c "import sys; print(sys.path)"

Frequently Asked Questions

Why does the module work in one terminal but not another?

Different terminals may have different Python environments active. Check 'which python' (Linux/macOS) or 'where python' (Windows) in each terminal to see which Python installation is being used.

How do I find the correct pip package name for a module?

Search on pypi.org for the package. Many packages have different install names and import names. The package's documentation will specify the correct import name.

Does ModuleNotFoundError mean the same as ImportError?

ModuleNotFoundError is a subclass of ImportError, introduced in Python 3.6. It specifically indicates that the module was not found, while ImportError can also cover cases where the module was found but something inside it failed to import.
