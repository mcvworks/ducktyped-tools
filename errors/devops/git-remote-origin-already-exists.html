fatal: remote origin already exists

Last updated: March 8, 2026

Git remote named 'origin' is already configured

You might see this error as:

  • Git remote origin already exists
  • fatal: remote origin already exists
  • error: remote origin already exists
  • git remote add origin failed

What Does This Error Mean?

This error occurs when you try to add a remote named 'origin' using 'git remote add origin', but a remote with that name is already configured in the repository. Each remote name must be unique within a repository. You need to update the existing remote URL or use a different remote name.

Common Causes

  • Repository was cloned from a remote — When you clone a repository, Git automatically creates a remote named 'origin' pointing to the source URL. Trying to add another origin will fail.
  • Origin was previously added — A 'git remote add origin' command was already executed in this repository, and you are running it again with a different URL.
  • Following setup instructions without checking existing remotes — Repository setup guides often include 'git remote add origin' as a step. Running these instructions on a repository that already has a remote configured causes this error.

How to Fix It

1. Update the existing remote URL

If you want to change where origin points, use set-url instead of add.

git remote set-url origin https://github.com/user/new-repo.git

2. Remove and re-add the remote

Remove the existing origin and add the new one.

git remote remove origin
git remote add origin https://github.com/user/repo.git

3. Use a different remote name

If you need both remotes, add the new one with a different name.

git remote add upstream https://github.com/user/repo.git
git remote -v

Frequently Asked Questions

What is the difference between 'origin' and 'upstream'?

By convention, 'origin' refers to your own fork or copy of a repository, and 'upstream' refers to the original repository you forked from. These are just naming conventions; Git does not enforce any special meaning.

Can I have multiple remotes?

Yes. You can add as many remotes as you want with different names. This is common when working with forks: 'origin' for your fork and 'upstream' for the original repository.
