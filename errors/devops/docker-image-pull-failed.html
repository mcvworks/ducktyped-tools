Docker Image Pull Failed

Last updated: March 8, 2026

Failed to pull a Docker image from the registry

You might see this error as:

  • Docker image pull failed
  • Error response from daemon: pull access denied
  • manifest unknown
  • repository does not exist
  • docker pull failed

What Does This Error Mean?

This error occurs when Docker cannot download an image from a container registry such as Docker Hub, GitHub Container Registry, or a private registry. The failure can be caused by network issues, authentication problems, or incorrect image names and tags.

Common Causes

  • Image name or tag does not exist — The specified image name or tag is incorrect, has been removed from the registry, or was never published. Docker cannot find the requested image.
  • Authentication required for private registry — The image is stored in a private registry or private repository that requires authentication, but Docker is not logged in or the credentials have expired.
  • Network connectivity issues — The machine cannot reach the container registry due to DNS resolution failures, proxy configuration, firewall rules, or general internet connectivity problems.
  • Registry rate limiting — Docker Hub and other registries enforce pull rate limits. Anonymous pulls from Docker Hub are limited to 100 per 6 hours, and authenticated free accounts get 200.
  • Platform architecture mismatch — The requested image does not have a build for the current platform architecture (e.g., pulling an amd64-only image on an arm64 machine).

How to Fix It

1. Verify the image name and tag

Double-check the image name and tag on the registry website. Ensure the repository exists and the tag has been published.

docker pull nginx:latest
# If using a private registry:
docker pull registry.example.com/myapp:v1.2.3

2. Log in to the container registry

Authenticate with the registry before pulling private images.

docker login
# For other registries:
docker login ghcr.io
docker login registry.example.com

3. Check network and DNS

Verify that the machine can resolve and reach the registry. Test DNS resolution and connectivity to the registry endpoint.

nslookup registry-1.docker.io
curl -I https://registry-1.docker.io/v2/

Frequently Asked Questions

What are Docker Hub pull rate limits?

Anonymous users get 100 pulls per 6 hours per IP. Authenticated free accounts get 200 pulls per 6 hours. Paid Docker subscriptions have higher or unlimited limits.

How do I pull an image for a different architecture?

Use the --platform flag: 'docker pull --platform linux/amd64 nginx:latest'. This works when the image has multi-architecture manifests.

Can I use a mirror to avoid rate limits?

Yes. You can configure a registry mirror in Docker's daemon.json file. Many cloud providers offer their own mirrors, and you can also set up your own with tools like Harbor or Nexus.
