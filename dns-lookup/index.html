DNS Record Types Explained
TypePurpose
AIPv4 address the domain points to
AAAAIPv6 address the domain points to
MXMail servers that handle email for the domain
TXTText records (SPF, verification, etc.)
NSNameservers authoritative for the domain
CNAMEAlias pointing to another domain name
SOAStart of Authority — zone admin info
CAAWhich CAs can issue SSL certs for the domain
