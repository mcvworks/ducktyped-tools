SMTP Server Checker

Last updated: March 10, 2026

Look up a domain's MX records and test whether its mail server accepts connections on the submission ports (465, 587). Port 25 can't be tested from our server — hosting providers block it to prevent spam — so we tell you that instead of showing a false negative.

Example uses:

Verifying a new mail server is reachable, troubleshooting email delivery failures, checking if an ISP is blocking port 25, or validating MX record changes.

SMTP Server Checker

Test SMTP server connectivity and verify email server configuration. Check if your mail server accepts connections on common SMTP ports.

Enter a domain (e.g. gmail.com) or specific MX host (e.g. alt1.gmail-smtp-in.l.google.com)
SMTP Ports Explained
PortProtocolPurpose
25SMTPServer-to-server mail relay (often blocked by ISPs)
465SMTPSSMTP over implicit TLS (legacy but widely used)
587SubmissionClient-to-server mail submission with STARTTLS

Most modern email clients use port 587 for sending. Port 25 is mainly for server-to-server relay.
