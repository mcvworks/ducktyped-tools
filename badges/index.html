How the Badges Work

            
Each badge is a small SVG image served from ducktyped.xyz/badges/. The snippet wraps it in a link to a duckTyped tool with your domain in the query string, so anyone who clicks it lands on the SSL Certificate Checker, DNS Record Checker, or Security Headers Checker with your domain already filled in, ready to run the check themselves.

            
The badge is a static image: no tracking pixel, no script, no cookies. Every visitor gets the same file and the image URL carries no identifier. The SVG is self-contained, with no external fonts or images, so it renders the same in a GitHub README, a docs site, or an email.

Badge FAQ

            

                

                    
Do duckTyped badges track my visitors?

                    
No. Each badge is a static SVG file with no script, no cookies, and no tracking pixel. Every visitor receives the same image and the image URL carries no identifier. duckTyped does not run analytics.

                

                

                    
Does the badge show the live status of my domain?

                    
No. The image is static and looks the same for every domain, so it never shows a pass or fail result. Clicking the badge opens the duckTyped tool with your domain already filled in, where the visitor can run the live check.

                

                

                    
Where can I use the badges?

                    
Anywhere that renders Markdown or HTML images: GitHub, GitLab, and Codeberg READMEs, documentation sites, status pages, and blog footers. Use the Markdown snippet for READMEs and the HTML snippet for web pages.

                

                

                    
Are the badges free, and can I host them myself?

                    
Yes. The badges are free to use with no account or sign-up. Each SVG is fully self-contained, with no external fonts, images, or scripts, so you can also download the file and serve it from your own site.
