JWT Decoder

Decode JSON Web Tokens to inspect header, payload, and claims. Check expiration status and issued-at time. Runs entirely in your browser.

A JWT has 3 parts separated by dots: header.payload.signature
Common JWT Claims
ClaimMeaning
subSubject (user ID)
issIssuer (who created the token)
audAudience (intended recipient)
expExpiration time (Unix timestamp)
iatIssued at (Unix timestamp)
nbfNot before (valid after this time)
jtiJWT ID (unique identifier)
