Email Header Analyzer

⛶ Open full page Learn

Parse and analyze email headers to troubleshoot delivery issues. Check SPF, DKIM, DMARC authentication and trace email routing path.

How to get email headers:
Gmail: Open email → Click ⋮ (three dots) → "Show original" → Copy all text
Outlook: Open email → File → Properties → Copy "Internet headers"
Yahoo: Open email → More → "View Raw Message"
Apple Mail: View → Message → All Headers → Select and copy

What we analyze:
• Email routing path (all servers the email passed through)
• Delivery timeline and delays
• Sender information (IP, domain, SPF/DKIM/DMARC status)
• Authentication results (SPF, DKIM, DMARC)
• Spam score and filtering information
• Reply-To and Return-Path details
• Message-ID and threading information

Site Info & FAQ

🔒 Privacy & Security: Most tools run entirely in your browser and send nothing anywhere. Network tools (DNS, WHOIS, SSL, port scan and similar) are run by our server, so it sees what you look up. No accounts, no cookies, no ad or analytics trackers. Full details.

💾 Settings Storage: Your preferences (tool visibility, theme, layout) are saved locally in your browser using localStorage. These settings persist across visits.

🎨 Customization Features:

  • Quick Search: Press / anywhere on the page to jump to the search bar. Press Esc to clear and close
  • Category Filters: Use the filter pills below the search bar to narrow tools by category
  • Recently Used: Tools you use are remembered and shown as quick-access chips at the top of the page
  • Drag & Drop: Turn on Organize in the ⚙ Customize panel, then drag tool cards into your preferred order
  • Show/Hide Tools: Toggle individual tools on/off in the ⚙ Customize panel above the tool grid
  • Day/Night Theme: Switch between dark and light themes with the plug toggle button
  • Layout Reset: Return all tools to their original order with the "Reset Layout" button

⚡ Smart Caching & Performance: Responses are cached locally to speed up repeated queries and reduce API usage. Cache durations vary by tool type (1 minute to 30 days based on data stability).

📊 Rate Limits & API Usage: To ensure fair usage and stay within free tier API limits, the following rate limits apply:

  • DNS Checker: 45 requests/minute, 1,500/day
  • WHOIS Lookup: 45 requests/minute, 1,000/day
  • ISP Checker: 45 requests/minute, 1,000/day
  • MAC Lookup: 30 requests/minute, 1,000/day
  • SSL/Port Scanner: 60 requests/minute, 10,000/day
  • Device Lookup (Dell): 30 requests/minute, 1,000/day (IMEI & Apple lookups are offline — no limits)
  • Note: You'll receive warnings when approaching limits. Type showAPIUsage() in browser console to view your current usage.

🗑️ Settings Reset: Your saved settings will be cleared if you:

  • Clear your browser cache or cookies
  • Use incognito/private browsing mode
  • Switch to a different browser or device

❓ Frequently Asked Questions

What is duckTyped?

duckTyped is a free collection of IT professional tools for DNS checking, SSL validation, password generation, WHOIS lookup, and network diagnostics. All tools work in your browser with no registration required.

Is duckTyped completely free?

Yes! All tools are 100% free with no hidden fees, no registration, and no credit card required. We believe IT tools should be accessible to everyone.

Is my data private and secure?

Yes! Most tools process everything client-side in your browser. Your data never leaves your device. We don't collect, store, or share any personal information.

Can I use these tools offline?

Most tools work offline! The Password Generator, Plain Notes, and Encrypted Note Sender work without internet. Network tools like DNS Checker and WHOIS Lookup require connectivity.

What tools are included?

We offer more than 55 free tools across network, security, email, web/URL, QR, lookup, and developer categories — including a DNS record checker with SPF/DKIM/DMARC validation, SSL certificate checker, WHOIS/IP lookup, port scanner, password generator, JSON formatter, regex tester, JWT decoder, email header analyzer, SMTP checker, QR code tools, and URL safety, redirect, and broken-link checkers.
