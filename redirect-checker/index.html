Frequently Asked Questions

What does this redirect checker follow?

The checker sends server-side GET requests and follows HTTP 301, 302, 303, 307, and 308 responses with a Location header. It records up to 15 responses and does not execute JavaScript or HTML meta refresh.

Does a final URL mean the page works?

Check the last HTTP status. A destination can return 404 or 5xx, or show a login page with status 200. A trace that stops at another redirect has no confirmed final destination.

Can I test POST redirects or my signed-in session?

This tool uses public GET requests and does not reproduce your browser session or POST body. Use your browser network panel or a controlled client test for those cases.

What is the difference between 301 and 302?

301 describes a permanent move; 302 describes a temporary one. Either can change a followed POST to GET. Use the redirect comparison guide for method preservation, caching, and search behavior.
